## Why

第一阶段只在本机保存作品，换设备无法续写。第二阶段在已有微信身份和可靠本地存储之上，提供主动微信登录、私有云作品及单设备续写，保留未上传内容的恢复路径。

## What Changes

- 点击微信登录后自动同步；可选头像昵称、个人中心及退出登录。
- 按手机预览反馈补齐品牌开屏与独立微信授权登录页；首次登录自动建号，在线功能入口直接衔接登录并返回原作品。个人中心按资料、作品工具、退出分组，正常状态不堆叠说明与重连按钮。按最新反馈必须登录才能进入产品，移除游客跳过和登录按钮上下的说明。
- 同账号单有效账号会话，云作品编辑前拉取最新，离线保住输入后暂停；本机草稿仍可写。
- 完整写作快照、持久同步队列、服务端版本与幂等操作、删除标记和恢复稿。
- JSON v6 保存未发送输入，接受 v1–v5，超限分卷。
- **BREAKING** 新客户端不再后台自动登录，已启用账号的旧客户端需升级；云作品不再允许持续离线修改。
- 真实本地网关/SQLite 联调，微信换码在自动化中使用替身；不自动部署、上传或调用计费服务。

## Capabilities

### New Capabilities
- `account-cloud-work-sync`: 账号资料、云作品权限、单设备同步、冲突恢复与生命周期。

### Modified Capabilities
- `wechat-identity-session`: 主动账号登录、旧身份兼容隔离及账号数据持久化。
- `miniprogram-local-persistence`: 账号空间、云同步状态与完整输入备份。
- `local-writing`: 本机草稿与云作品编辑边界。
- `product-design-system`: 真实个人中心与同步状态。

## Impact

影响共享领域、服务端身份库、小程序仓储/编辑/个人中心/备份、Nginx 和数据库运维脚本；新增服务端 sharp 依赖，不新增外部服务。后台账号和 H5 边界保持独立；原始音频不保存，账号和 token 不进入备份。
