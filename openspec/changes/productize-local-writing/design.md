## Context

本次产品化从已验收的设计原型起步，原型的页面及 mock 混在单文件中且无持久化。用户批准本地优先、真实语音和独立 AI 演示，并指定 oldman Public 仓库。当前唯一正式工程位于 oldman 根目录，原型源码和空迁移源目录已清理；项目统一使用“岁月有声”“正式版”或“当前工程”。每个通过检查的小阶段自动本地提交，不发布站点。

## Goals / Non-Goals

**Goals:** 保持 UI；建立规范；实现真实写作、本机恢复、备份和受控语音网关。

**Non-Goals:** 账号、云端作品、真实生成式 AI、公开服务、永久原音保存、真机 HTTPS 部署。

## Decisions

- 以已验收设计基线（Git 提交 `28fd5e4`）的页面结构和样式为准，产品化不等于新增一套界面。首页仅保留原有更多、作品卡片和开始写作入口；卡片不增设菜单或额外右留白。备份、作品管理及回收恢复集中到原有首页更多弹层；AI 演示仅从原编辑器的聊天/优化入口进入。
- 编辑器不加常驻保存工具行。保存中/失败复用原保存按钮及失败提示，成功由读屏状态和手动保存反馈表达；不挤压正文、转写区或麦克风。单段编辑保留已验收的提示与字数，真实写入逻辑不回退。卡片时间由真实时间生成今天/昨天/中文日期，保留已验收的字号、布局与本机保存语义。
- 沿用 npm/Vinext；业务组件不依赖框架 API，暂不迁移工具链。安全更新在同一工具链内升级并重跑检查与构建。
- `features/writing` 管理工作副本，`lib/storage` 暴露 WorkRepository。IndexedDB v1 使用 works 和 recovery 两个 store；逐次串行事务、乐观 revision 检查，多标签冲突不静默覆盖。
- 编辑快照包括 title、segments、textDraft、inputMode、pendingVoice、单段编辑缓存。保存恢复快照和作品在同一事务提交；空白新建只保存恢复状态，不生成空作品。手动保存必须等待落盘。
- 备份 JSON 使用 schemaVersion=1；导入全部校验后事务创建新 ID 副本；未知版本拒绝且不修改数据库。TXT 包括标题/正文，待确认语音或未完成编辑附明确标注，避免故障补救导出遗漏。
- `features/demo` 只接收副本和退出回调，不导入存储/语音网关。保留旧交互；顶部持续显示演示标识。
- 浏览器通过 AudioWorklet 采集 16kHz PCM16 单声道；同源 `/api/speech` 代理到回环地址 Node/Fastify 网关。网关只接受已配置 Origin、固定腾讯云上游、最大 5 分钟、最大 10MB 和有限连接数。
- `SpeechSession` 以会话代号隔离迟到回调；每句按 index 覆写临时结果，最终结果收尾后才完成；结束采音立即停止全部 tracks。短按、授权期间松手及取消不能偷偷开始录音。
- 网关环境变量读取密钥，不返回签名或密钥，不记录音频/正文。没有凭据时 503，真实入口不回退 mock。原音仅为瞬时采音缓冲。
- `ASR_CREDENTIAL_SOURCE` 默认 `project`；显式 `windows-user` 时仅网关进程用固定 PowerShell 命令读取 Windows User 的既有凭据，捕获输出只在内存解析，不回显或写入文件。读取有超时和大小限制；异常信息仅返回固定提示。AppID 仍由项目配置，不合并不同来源的 SecretId/SecretKey/Token。
- 小规模真实语音联调先简单估算费用和总规模，低成本且必要时可按需执行，无需逐次确认；大批量自动化测试、压测、长时间循环或费用较高、不确定时先确认预算和上限。显式 `--pcm` 联调最多 30 秒，默认无音频只检查本地配置；限制调用次数与重试，不自动充值/购买/调整计费。成功后 `.env.local` 仅保存 AppID、凭据来源和非秘密选项，既有密钥不复制到工程；临时凭据才需要 Token。
- 开发固定 localhost:3001，代理 127.0.0.1:3002；严格端口，避免 origin 改变。常规回归与 CI 不调用计费外部服务，不产生语音费用；业务逻辑按需使用真实实现或测试替身，真实联调使用独立显式入口。
- 日常直接在 main 开发，不强制功能分支或 PR，仍保留 OpenSpec 和自动本地提交。AGENTS 只记录长期开发、安全与验收规则，阶段授权和完成状态留在变更及验收记录；本次文档调整不切换或合并现有分支，不推送远端。
- AGENTS 以规范入口、工作流程、权限与安全、验证与交付组织。机器路径、历史称谓和 AI 功能模拟实现不作为长期规则；仓库根目录按当前环境定位。已确认范围内普通实现与内部类型调整无需重复确认，越界、破坏兼容性、数据丢失风险或新增外部操作需明确授权。文档改动检查差异、引用与相关规范；代码、运行链路、界面按影响增加检查，代码阶段交付与 CI 保留完整回归。
- 聊天、优化、配图仍是待接入 AI 的功能，既有 `features/demo` 与 `isolated-ai-demo` 是当前实现标识，不代表另一个演示产品。其副本隔离、mock 交互和页面现有提示本次不改，具体边界由功能规范、架构和测试维护，未来接入方案另行确认。
- 2026-08-28 用户确认不再使用 GPT Sites：移除 `.openai/hosting.json`、Sites Vite 插件、Cloudflare Vite 插件、Worker 类型及 Wrangler 直接依赖，同时更新 npm 锁文件。开发与构建均保留 Vinext 的本地 Node 链路，不迁移框架，不新增发布平台；不删除或更新远端站点。此前 Cloudflare 开发插件曾与语音代理争抢升级请求，保留同源 WebSocket 与 Origin 校验回归，不改写来源或绕过鉴权。

## Risks / Trade-offs

- 浏览器数据会被清理 → 显示本机边界，提供全量备份恢复，写失败时允许导出内存副本。
- 多标签竞争 → revision 冲突明确提示，保留当前副本和导出路径。
- 老设备/浏览器录音不兼容 → 特性检测与文字输入兜底；真机验收独立记录。
- Vinext beta → 保留可运行基线、锁依赖，正式上线前另评估。
- 无凭据无法真实联调 → 契约测试只证明代码行为，不冒充识别效果验收。

## Migration Plan

先冻结 Git 基线，再分离模块、启用存储和语音。旧 Demo 无持久化用户数据，无迁移来源。数据库未来升级以事务执行且禁止 catch 后删库重建。回退代码前导出真实数据；不自动修改或降级数据库。

2026-08-28 工程统一到 `D:/vibe_code/oldman` 根目录，不保留另一份活动工程或额外退役备份。清理前核对原型无独有配置、未提交改动或用户数据；正式工程的 `.git`、`.codex`、`.env.local` 和全部本地文件完整迁入。每个目标先验证绝对路径，不合并同名目录、不删除工作区根目录；迁移后核对文件哈希、Git refs、环境文件与启动结果。浏览器地址和 IndexedDB 名称不变，不触碰浏览器数据或云端配置。

实施结果：正式工程全部 39 个顶层条目已迁入 oldman，88 个文件和 Git refs 校验一致；空迁移源目录已由用户删除并核实不存在。有效文档统一当前根目录及正式版称谓，Sites 本地接入已移除。残余空备份/配置目录及停用缓存作为独立任务 4.9 保持待办，不影响正式工程使用。
