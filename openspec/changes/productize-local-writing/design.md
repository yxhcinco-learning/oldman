## Context

V2 已验收，页面及 mock 混在单文件中且无持久化。用户批准本地优先、真实语音、独立 AI 演示；后续指定 oldman Public 仓库，V2 为正式版，原 Demo 备份后清理。每个通过检查的小阶段自动本地提交，不发布站点。

## Goals / Non-Goals

**Goals:** 保持 UI；建立规范；实现真实写作、本机恢复、备份和受控语音网关。

**Non-Goals:** 账号、云端作品、真实生成式 AI、公开服务、永久原音保存、真机 HTTPS 部署。

## Decisions

- 沿用 npm/Vinext；业务组件不依赖框架 API，暂不迁移工具链。安全更新在同一工具链内升级并重跑检查与构建。
- `features/writing` 管理工作副本，`lib/storage` 暴露 WorkRepository。IndexedDB v1 使用 works 和 recovery 两个 store；逐次串行事务、乐观 revision 检查，多标签冲突不静默覆盖。
- 编辑快照包括 title、segments、textDraft、inputMode、pendingVoice、单段编辑缓存。保存恢复快照和作品在同一事务提交；空白新建只保存恢复状态，不生成空作品。手动保存必须等待落盘。
- 备份 JSON 使用 schemaVersion=1；导入全部校验后事务创建新 ID 副本；未知版本拒绝且不修改数据库。TXT 包括标题/正文，待确认语音或未完成编辑附明确标注，避免故障补救导出遗漏。
- `features/demo` 只接收副本和退出回调，不导入存储/语音网关。保留旧交互；顶部持续显示演示标识。
- 浏览器通过 AudioWorklet 采集 16kHz PCM16 单声道；同源 `/api/speech` 代理到回环地址 Node/Fastify 网关。网关只接受已配置 Origin、固定腾讯云上游、最大 5 分钟、最大 10MB 和有限连接数。
- `SpeechSession` 以会话代号隔离迟到回调；每句按 index 覆写临时结果，最终结果收尾后才完成；结束采音立即停止全部 tracks。短按、授权期间松手及取消不能偷偷开始录音。
- 网关环境变量读取密钥，不返回签名或密钥，不记录音频/正文。没有凭据时 503，真实入口不回退 mock。原音仅为瞬时采音缓冲。
- 开发固定 localhost:3001，代理 127.0.0.1:3002；严格端口，避免 origin 改变。自动测试不产生语音费用。

## Risks / Trade-offs

- 浏览器数据会被清理 → 显示本机边界，提供全量备份恢复，写失败时允许导出内存副本。
- 多标签竞争 → revision 冲突明确提示，保留当前副本和导出路径。
- 老设备/浏览器录音不兼容 → 特性检测与文字输入兜底；真机验收独立记录。
- Vinext beta → 保留可运行基线、锁依赖，正式上线前另评估。
- 无凭据无法真实联调 → 契约测试只证明代码行为，不冒充识别效果验收。

## Migration Plan

先冻结 Git 基线，再分离模块、启用存储和语音。旧 Demo 无持久化用户数据，无迁移来源。数据库未来升级以事务执行且禁止 catch 后删库重建。回退代码前导出真实数据；不自动修改或降级数据库。
