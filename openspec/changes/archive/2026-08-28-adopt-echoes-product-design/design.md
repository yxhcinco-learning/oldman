## Context

用户明确批准将当前 Echoes 预览全面应用到正式产品。本请求替代旧规范中“不重设计”、430px桌面宽度、旧字体及标题提示的视觉约束，不改变此前确认的数据与服务边界。视觉来源为 `7bdd75c`，后续排版小修见同目录 Git 历史。

## Goals / Non-Goals

**Goals:** 更新唯一有效的设计规范；作品、输入、真实语音状态、AI 模拟和全部正式弹层采用一致视觉；保持数据及功能回归。

**Non-Goals:** 数据迁移、真实 AI、语音协议变更、模拟键盘回归、示例作品灌入、字体服务安装、推送或部署。

## Decisions

- 正式设计入口仍为 `DESIGN-SYSTEM.md`，改写为 Echoes 的 tokens、组件和真实状态规范；独立预览保留为对照，不将其说明与正式规范并列生效。
- 将纯 SVG 插画/图标和统一工具栏提取到正式 `components`，正式运行时不 import `previews`。不复制预览的状态机、mock、假保存或键盘。
- 以新预览 CSS 为基础重建正式样式，删除已替代旧规则，保留 Tailwind/Vinext 构建链路；补齐原生 dialog、保存失败、空列表、语音连接/错误及模拟标识。
- 真实输入和存储逻辑保持现有模块；正文两种模式共享18px/32px度量、自然段空行，标题26px/36px与浅横线，两种模式同一位置；工具栏短标签保留完整可访问名称。
- 语音布局固定122px文字阶段、84px操作行、20px辅助行；正文至少90px/30px三行。错误/等待文案不挤走麦克风；实际波形仍依据音量，模拟波形只在AI副本。
- 作品卡片使用真实日期与字数；封面使用按稳定ID分配的装饰SVG，不推断文章内容或保存新字段。长标题、完整时间自然换行。
- 原生键盘、保存中/失败语义、备份/回收站入口、AI 副本及模拟标识不改变；同一设计风格并不意味着把模拟功能变成真实AI。
- 视觉指纹更新基于用户批准的新基线，并增加语义样式/结构测试；完整业务测试继续执行，不删减数据和错误检查。

## Risks / Trade-offs

- 原型文案/模型误入真实产品 → 仅移植展示层，检查正式模块依赖与测试原有作品恢复、保存失败和AI隔离。
- 小屏/错误文本占位导致麦克风位移 → 固定网格、独立滚动，浏览器与可控语音状态测试量测。
- 字体跨设备差异 → 保留已确认系统回退，不引入远程字体；真机字形与系统键盘后续验收。
- 历史规范冲突 → 更新现行设计、开发上下文与 editor-presentation 增量；历史验收记录加指向新规范的说明，不篡改旧测量。

## Migration Plan

没有数据库或账号迁移，仍使用 localhost:3001 和现有存储。先文档与提案，再组件/样式、自动测试、浏览器回归；完成后自动归档及本地提交。回退仅涉及本次展示提交，不改历史标签或用户数据。
