## Context

原版源码提交为 `01457f33cdc09229a9280b8cdd9aae7b99e6c5e1`，已恢复为参考文件。用户要求按新 DESIGN.md 重做原版以评审设计，不修改正式版；与正式版设计基线的差异只存在于独立原型。

## Goals / Non-Goals

**Goals:** 一套完整且可操作的 Echoes of Time 视觉预览，覆盖主流程及弹层、录音、空白状态；本地可启动、可回退。

**Non-Goals:** 正式版换肤、真实保存/语音/AI、用户数据迁移、公开部署或重新接入 Sites。

## Decisions

- 在 previews 下独立维护 React 原型，不另建仓库、依赖清单或正式项目。原版交互逻辑与 mock 保留，新的样式从零组织，避免覆盖正式全局 CSS。
- 使用用户文档的顶部 token：surface #fbf9f8、primary #153b2e、secondary #944924；文中另一纸色 #F4F1E8 只作插画和细节的辅助色，避免两套主背景并存。
- 标题用 Noto Serif / 中文衬线回退，正文与界面用 Manrope / 中文无衬线回退，不依赖远程字体。正文18px/30px，移动标题26px/36px；移动24px边距、小屏20px，桌面最大800px。
- 统一16px卡片与胶囊按钮，SVG线描插画使用同一色板；不额外生成位图或安装设计平台。
- 编辑器将输入切换与辅助入口收敛到一行，转写区和麦克风使用固定网格，不因状态转换位移；保留原生编辑及模拟键盘。
- Node 入口复用已安装 Vite，在内存打包并输出独立 HTML，仅绑定 127.0.0.1:3004；固定端口、禁用环境文件加载、不提供目录浏览或任意文件路由。HTML 与截图写入忽略的 outputs，源码跟踪提交。
- 模拟录音不访问麦克风，模拟保存只在内存；刷新复位。与正式业务无导入、存储或服务调用关系。

## Risks / Trade-offs

- 本机未安装指定字体 → 中文按衬线/无衬线语义回退，并明确不宣称字体文件已加载。
- 原版交互与新布局不匹配 → 测试模式切换、长按/取消、单段、聊天整理、优化/撤销，浏览器复核各屏及麦克风位置。
- 误把方向稿当正式验收 → 预览说明明确仅供评审，不自动修改正式设计规范或业务数据。

## Migration Plan

无需迁移。关闭预览服务不影响正式3001；设计采纳需要后续确认和独立变更。
