## Why

目标用户在微信内无法顺畅完成浏览器 Basic Auth，且现有 H5 依赖 IndexedDB、DOM、Web Audio 与浏览器手势，不能直接作为可靠的小程序体验。现在需要增加一个原生微信小程序客户端，用微信无感身份替代可见登录门槛，同时保持作品本地优先、现有写作闭环和网页端继续可用。

## What Changes

- 在同一仓库增加原生 TypeScript 微信小程序客户端，覆盖“热门 / 文章 / 我的”、普通写作、话题背景、小文采访、文章会话、修改确认、版本记录、回收站与备份恢复；功能语义与当前正式版一致，平台不支持的 DOM 手势改成明显、可学习的原生交互。
- 抽取或建立可被网页端、小程序端和服务端共同验证的领域模型、协议与固定文案边界；浏览器和微信专属能力通过独立适配器实现，不复制相互漂移的业务规则。
- 用户首次打开时调用 `wx.login`，服务端以 `code2Session` 换取当前 AppID 下的 OpenID，创建最小内部用户并签发自有会话；不要求注册，不主动请求手机号、头像、昵称或公开账号资料。
- 增加仅保存用户、微信身份和可撤销会话的服务端持久化。第一版作品、采访素材、版本和小文会话仍只保存在当前小程序的本地用户文件中，不提供云端作品或跨设备同步。
- 以小程序本地用户文件保存按作品拆分的数据，以小型索引协调列表与恢复；继续提供有版本校验、大小限制和导入为副本语义的手工 JSON 备份，不把“本地已保存”描述成云备份。
- 用 `RecorderManager` 的 16 kHz 单声道 PCM 分片和 `wx.connectSocket` 接入现有腾讯云 ASR 网关，用 `wx.request` 接入现有话题与 DeepSeek 能力；保持取消、失败、限额、明确发送和候选确认边界。
- 将现有公网部署拆成网页访问保护和小程序 API 鉴权两条边界：网页继续使用 Basic Auth，小程序登录入口与已鉴权 API 不依赖浏览器 Origin 或 Basic Auth；语音连接使用短时、单次凭证，不在 URL、日志或客户端包中暴露长期秘密。
- 使用 `ask_job` 的真实 AppID 作为本机未跟踪的临时开发配置，只用于开发与体验版。正式 AppID 更换时视为新的微信身份和本地存储空间，不承诺自动迁移临时 AppID 下的数据。
- 增加小程序隐私指引、麦克风和 AI 数据外发知情说明、AI 生成合成内容标识、合法域名、备案/类目、体验版与真机验收清单；上传、提审和发布仍需用户单独明确授权。

## Capabilities

### New Capabilities

- `wechat-miniprogram-client`: 原生小程序的信息架构、核心写作闭环、平台适配、网页并存和交互等价要求。
- `wechat-identity-session`: 无感微信身份、最小用户记录、业务会话、API 与 WebSocket 鉴权及临时 AppID 边界。
- `miniprogram-local-persistence`: 小程序本地文件仓储、恢复、冲突、回收站、备份导入导出和容量/清理失败处理。
- `ai-content-labeling`: 小文生成候选在交互、复制、导出和审核材料中的显式标识与可追溯要求。

### Modified Capabilities

- `project-foundation`: 正式工程从单一 H5 客户端扩展为网页、小程序、共享核心与现有网关共同维护的项目。
- `local-writing`: “本机保存”扩展到小程序本地用户文件，同时继续排除第一版云端文章与跨设备同步。
- `speech-input`: 除浏览器 AudioWorklet 外增加小程序原生录音与分片传输，并保持原有状态、取消和隐私边界。
- `controlled-public-deployment`: 在不削弱网页 Basic Auth 的前提下增加面向小程序的 HTTPS/WSS、业务会话、持久数据目录和发布前平台配置。

## Impact

- 代码与工具链：新增小程序工程、共享领域/协议边界、微信开发者工具检查和小程序专属测试；现有 React/Vinext 网页继续保留。
- 服务端：Fastify 增加微信换码、用户/身份/会话、短时语音凭证和鉴权钩子；需要独立于 release 的小规模持久化与备份。
- 部署：Nginx 路由、限流、运行时环境变量、systemd 可写目录、合法 request/socket 域名和隐私配置发生变化；AppSecret 只由用户写入服务器受限环境文件。
- 数据：网页 IndexedDB 与小程序本地文件互不自动同步；临时与正式 AppID 的本地数据和 OpenID 也互相隔离，只能通过明确的备份导入迁移作品副本。
- 安全与合规：新增微信身份数据、会话令牌、麦克风授权和 AI 标识审查；常规测试使用替身，不调用计费微信、腾讯云或 DeepSeek 接口。
