## Why

岁月有声的核心切入人群是有阅历、有判断和文字表达意愿的退休知识人群；他们通常不是不会写，而是缺少“今天值得写什么、从哪个角度写、材料从哪里来”的稳定启动条件。产品需要从单纯等待用户带着正文进入编辑器，扩展为以可信议题激发表达、再由小文陪伴成文的内容型写作工作台。

## What Changes

- 增加克制的“今日值得写 / 本周主题”议题入口，提供经过筛选的当下事件、周期主题与慢议题，不建设无限新闻流；每个议题标明事实摘要、来源、更新时间和若干可写角度。
- 用户从议题进入写作时可自由选择两条平行路径：直接进入正常写作，或进入由小文逐问引导的采访模式；不强迫用户先聊天或先生成提纲。
- 将采访定义为小文的一种明确工作模式，而不是恢复一个与小文并列的通用“聊天”产品或第二个助手。小文一次只问一个与议题、用户职业经历或已回答材料有关的问题，回答先作为可检查素材，不自动写入正文。
- 正常写作继续提供完整编辑器；选中的事件以可收起的文章背景保留，用户可查看来源和角度，也可完全按自己的结构写作。背景事实、用户观点、采访素材和 AI 候选 MUST 保持来源区分。
- 用户可随时结束采访、切回正常写作或稍后继续，已有素材、正文和事件背景不丢失；只有用户明确请求成文并确认候选后，采访素材才能进入正文。
- MVP 的议题由人工选择、AI 辅助加工并经人工确认后发布；不自动把热搜或开放网络内容直接展示给用户，不把 AI 摘要冒充原始事实。
- 本变更不建设公开评论区、关注关系、开放投稿社区、自动公开发布、分钟级突发新闻、长期自主 Agent 或第二套聊天会话；作品仍按当前边界由用户掌控。

## Capabilities

### New Capabilities

- `writing-topic-feed`: 定义面向目标人群的精选议题、可信来源、更新时间、写作角度与克制的内容入口。
- `topic-guided-writing`: 定义从议题进入正常写作或小文采访的双路径，以及事件背景、采访素材和正文之间的可逆切换与来源边界。

### Modified Capabilities

- `article-ai-session`: 增加由用户主动选择的小文采访模式，保持单问题引导、素材先行、明确成文和候选确认边界。
- `local-writing`: 允许作品关联可核对的议题背景与采访素材，并在本机保存、恢复、备份和模式切换中保持来源与正文分离。

## Impact

涉及作品首页信息架构、议题详情与内容审核入口、议题及来源数据、作品/备份模型、编辑器背景面板、小文会话状态、AI 上下文和候选成文协议。议题内容需要联网获取和服务端发布，但第一阶段不要求账号、云端作品或社区关系；现有语音、文章编辑、候选确认和版本追溯可复用，数据升级必须兼容既有本机作品与 JSON 备份。
