# 岁月有声 H5 Demo · 设计优化副本

这是从原版独立复制出的 V2 设计优化稿，未关联原线上项目，原工程与线上版本均不会被本副本覆盖。语音识别、AI 对话和文章优化均为可交互的 mock，不会申请麦克风权限，也不会发送任何数据。

设计与审视文档：

- `DESIGN-SYSTEM.md`：可直接指导 AI 继续设计和实现的规范。
- `DESIGN-AUDIT.md`：本轮发现、调整与验收标准。

## 本地运行

```bash
npm install
npm run dev
```

打开终端输出的 `Local` 地址即可。若默认的 `3000` 端口已被占用，开发服务会自动选择下一个可用端口。

## 主要体验路径

1. 在“我的作品”点击“开始写作”。
2. 在语音模式长按麦克风，观察实时转写，松开后可清空、继续说或完成。
3. 点击刚刚录入的段落，可手动修改错字和标点。
4. 使用“聊天引导”体验微信式长按语音和 AI 追问。
5. 使用“文章优化”选择内容类型、文风、格式、配图或输入自定义要求。
6. 保存后，新作品会在本次会话中出现在作品列表顶部；刷新页面后恢复初始 mock 数据。
