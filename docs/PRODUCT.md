# 产品边界

岁月有声帮助长辈把想说的话写下来，不限于回忆，也可以是诗歌或生活随笔。

已实现：文字与段落编辑、本机自动保存及恢复、回收站、TXT 与 JSON 备份、腾讯云实时语音。

待接入 AI：聊天引导、文章优化、配图与自定义要求。当前以 mock 保留交互，使用作品副本并标明模拟状态；退出不影响真实内容。这是功能实现状态，不代表项目仍是 Demo。后续真实 AI 的行为与数据写回方案另行讨论，不由现有模拟实现固化。

本期不做：账号、跨设备同步、云端文章、真实生成式 AI 接入、公开服务、原音收藏、Word/PDF 导出。

## 保存语义

- 已保存只表示 IndexedDB 写入成功，不表示云备份或永久安全。
- 自动写入正文和未完成编辑；回收站不自动清空。
- 无标题作品用“未命名作品”；纯空白新建不出现在作品列表。
- 备份恢复为新副本，不覆盖；不同浏览器、域名、协议或端口数据互不相通。
- 断网时已打开页面可继续文字编辑，不承诺离线首次加载或离线语音识别。
