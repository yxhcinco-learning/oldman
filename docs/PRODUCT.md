# 产品边界

## 当前产品形态

岁月有声面向有阅历、有判断、有文字表达意愿的退休人群，帮助作者从经历与当下议题形成自己的文章。**小程序为唯一用户端，后台为对应运营端。** H5 是已退役的早期试验，专属源码与资料归档，不再参与后续功能、验收或账号同步设计。

## 产品能力

- 小程序“热门 / 文章 / 我的”：人工精选话题、直接写作、文字与语音、人工审核文章列表、我的文章、回收站、备份与好友分享。
- 每篇作品一个小文会话；访谈是开关，不是另一个助手。收起保持模式，结束访谈统一请求整理；候选需用户采用才改正文。问候、原始素材、AI 建议和已采用正文分层保存。
- 无话题时不显示空主题卡片，小文先问想聊什么；开启不自动调用模型。等待、失败、重试与正文状态分开。
- 本地文件聚合、版本、修订冲突保护和 JSON v6（含未发送的小文输入）；接受 v1–v5，导入创建副本，不覆盖旧作品。
- 品牌开屏后进入独立微信授权登录页，已有有效登录直接进入热门；首次登录自动建号并自动保存私有云作品。小文、采访和语音入口直接衔接登录，成功返回原作品，不自动录音或重发模型请求。同账号只保留一个有效会话，新设备接管后旧端需主动登录。必须登录才能进入热门、作品及个人中心；无会话仅能查看开屏、登录与隐私说明。已登录遇到临时断网仍保留本机写作能力。我的主页展示可编辑资料、写作入口、一篇最近草稿及两篇其他文章摘要；全部文章进入独立搜索/筛选/分页管理，每篇按状态保留单一入口，回收站在列表页头；设置保留隐私、退出及低频数据工具。自动同步默认在后台执行，正常页面不常驻同步/上传/云端标签；只有影响使用的异常才提示，保存详情在数据工具中查看。
- 运营后台负责话题编辑、AI 候选审核、不可变修订、五席排期、审计和用量监控，并独立审核作者投稿和下架已发表文章。后台管理账号不是用户账号。

## 维护范围

“网页”只指运营后台；“跨设备”只面向同账号的小程序设备，不包含 H5。活跃模块与依赖见[架构](ARCHITECTURE.md)。H5 专属 UI、IndexedDB、浏览器采音和四尺寸验收退出维护；共享领域、协议、安全与旧备份兼容继续有效。

历史源码在 [archive/h5](../archive/h5/README.md)，历史资料在 [docs/archive/h5](archive/h5/README.md)，只供追溯，不安装、编译、测试或发布。归档可通过 Git 恢复；退役不意味着获准停止旧线上站点、删除用户数据或移除兼容接口，线上状态与操作边界见[部署说明](DEPLOYMENT.md)。

## 数据与交互原则

正文、用户原话和来源事实不能被模型建议冒充。常规优化保留事实和原意，文风调整不能擅自编造人物关系、事件、数字或对话。只有显式采用修改正文；恢复和撤销保留历史。

“本机已保存”仅代表本机写入；“已同步”须对应内容收到云端确认。云作品先联网获取最新快照再编辑，断网保住当前输入并暂停编辑；本机新稿可离线继续。退出隐藏账号缓存并保留未上传恢复稿，换账号不更换原稿归属。冲突不自动合并，主作品采用云端最新，完整本机恢复稿可查看、导出或另存新篇。JSON 明文备份由用户保管，每卷及每次导入上限 10MiB；不清空旧 H5 的浏览器数据，旧备份仍可主动导入小程序副本。

录音在用户操作和授权后启动，不保存原音；小文输入中的识别文字可编辑，用户明确发送后才调用模型。发送给 DeepSeek 的正文、相关历史、话题与材料需知情同意。AI 结果不逐条堆叠旧核对标签；预览与对外导出保留相应来源说明，待采用不标作已经应用。

## 验收与非目标

第二阶段规格见 [账号与云同步规格](../openspec/specs/account-cloud-work-sync/spec.md)。云作品删除、恢复与永久删除需在线并校验最新版本；永久删除清除在线正文和会话，保留必要删除标记，不承诺立即擦除离线设备或历史运维备份。全部备份先补齐云端内容，离线仅导出明确标示的本机备份。阶段进展与真机证据见[当前状态](STATUS.md)。

文章发表阶段扩展为人工审核后的登录用户公共阅读及好友分享；不加入评论、点赞、关注、朋友圈或推荐算法。私有工作稿、投稿快照和公开版本分离，后台仅能查看明确提交的内容。用户名全站唯一，默认附数字编号，历史名字保留原账号归属；公开使用投稿署名和默认头像。原编辑器下一步进入发表设置，底部直接提交审核；阅读预览为按需打开的独立只读页面，改稿/改名无需再次预览，提交内部仍核对最新正文/设置/署名，裁切独立全屏；必选封面支持列表 1:1 与阅读/好友 5:4，JSON v6 不备份封面，导入副本需重新选图，不能继承发表身份。实现进度以 STATUS 和活跃发表变更为准。

不做 H5 用户端、H5 账号绑定或小程序/H5 实时同步；不把源码里保留的后端兼容路径理解为另一条产品线。不做多人协作、原音收藏或自动采用 AI。
