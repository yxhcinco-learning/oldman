# 产品边界

岁月有声帮助长辈把想说的话写下来，不限于回忆，也可以是诗歌或生活随笔。

已实现：当前页文字编辑、页头标题弹窗、语音待确认文字单独修改、本机自动保存及恢复、回收站、TXT 与 JSON 备份、腾讯云实时语音；DeepSeek V4 Flash 常规优化、润色文笔、文章追问和对话式改文。编辑器底部以一个小按钮在语音与文字输入间切换：文字态显示麦克风，语音态显示键盘，点击只切换输入方式，不自动开始录音。语音舞台空闲时可整体收起，正文单击恢复语音、快速点击两次或触屏长按切到当前页文字输入，切换后的插入光标落在第二次点击或按住的字符位置；标题在页头显示，点击后用普通文字输入弹窗编辑，确认才写回且不改变正文语音/文字模式，普通正文不再跳转单独段落编辑页。点击语音待确认文字后仍进入独立编辑页，光标会落在点击位置；左上“取消”保留原待确认文字，底部“完成修改”才写回。小文会话支持点按开始、再次点按取消语音采集，已经显示的识别文字继续可编辑，检查后仍由用户点击发送。

常规优化整理通顺、分段、用字和标点，并把无实际语义的口语填充、重复连接和松散句式改为自然书面表达；它允许必要的换词和句式调整，但不做文学化润色或以缩短篇幅为目的的精简，有意义的方言、直接引语、情感和叙述者个性仍需保留。润色文笔改善用词、描写与节奏，两者都要求保留事实和原意。点击快捷优化后进入文章会话，小文先输出只包含本轮实际差异的修改说明和独立的待应用状态；明确“未变”或把同一句改为自身的项目不会列作修改。用户再查看候选全文与原文并决定应用或放弃。AI 可能出错，用户仍需核对。没有实际变化时明确提示保留原文。标题不自动改写。

小文是编辑器中的单一、用户主动触发的文章伙伴，不等同于此前另行规划的“聊天”功能；本期只是移除当前没有实际能力的聊天占位入口，并把文章相关能力直接放进小文。点击叶片“小文”直接打开文章会话，不再经过优化菜单。第一期提供四个快捷意图：“接着问我”依据当前正文接住一个真实细节并只问一个容易回答的问题；“讲清楚了吗”最多指出三处有依据的表达缺口，已经清楚时直接说明；“帮我理顺”复用常规优化；“润色文笔”复用润色。前两项只返回回答，不生成候选正文；后两项仍需用户查看并确认候选。快捷项不读取或清空输入框里尚未发送的文字。

每篇文章有独立会话和版本：编辑停顿、AI 操作、修改说明、采纳/放弃和恢复可追溯，刷新仍保留。界面称为“修改记录”，按来源、分钟时间和字数展示，正文为空的起始记录不显示但仍保留在底层。小文默认以紧凑底部面板打开且不抢输入焦点，可由页头按钮显式展开，聚焦输入框时也会展开；消息独立滚动，输入和四个两列快捷项固定在底部。会话输入区空内容固定一行，不受提示词长度影响，输入后随文字增长到限定高度，语音与“发送”同组；同一次自由输入请求会根据文字回答问题，或按明确要求生成完整候选，不明确时先用短句询问。候选确认前不改正文，采用后可撤销。修改说明是小文的回答内容，待应用、已应用和未采用只表示候选状态，状态变化不会覆盖说明。修改记录从页头48px图标进入。

关闭或 Escape 只把小文收起，并把焦点还给编辑器入口；当前作品未发送的输入保留在内存，进行中的请求继续。收起期间入口以文字和非颜色状态显示“正在处理 / 有新回复 / 需要处理”，重新打开后清除入口提醒但保留真实会话、失败和候选。只有用户点击“取消请求”、离开当前作品或页面销毁才终止请求。未发送输入不写入 IndexedDB、备份或网络，离开作品即清空。

对话调整可按明确要求改写、删除、重排内容，或加入本轮由用户明确提供的事实。文风要求可以合理改变修辞、节奏、情绪色彩和不影响核心事实的氛围表达，但不得擅自改变人物关系、谁做了什么、时间地点、数字、对话和事件结果，标题不自动修改。模型仍可能违反要求，预览会提示重点核对，不提供自动事实保证。正文最多 12000 字，较长历史会选取相关部分发送，全部已存版本仍可在本机查看。不能找回开始记录以前已丢失的文字。

本期不做小文主动读取内容后自动“捧哏”、悬浮头像、自由拖动、后台主动弹出、自动来回语音聊天，也不展示精简、扩写、配图等未来能力占位。以后增加能力需先验证触发价值、打扰程度和事实风险。旧模拟源码仅保留独立测试，不作为正式入口或失败兜底。

本期不做：账号、跨设备同步、云端文章、无访问保护的公开服务、原音收藏、Word/PDF 导出。2026-08-30 起允许在固定 HTTPS Origin 和反向代理访问保护下进行少量同事的临时公网测试；这不是正式开放，也不改变产品的数据模型或功能范围。

## 保存语义

- 已保存只表示 IndexedDB 写入成功，不表示云备份或永久安全。
- 自动写入正文和未完成编辑；回收站不自动清空。
- 无标题作品用“未命名作品”；纯空白新建不出现在作品列表。
- 备份恢复为新副本，不覆盖；不同浏览器、域名、协议或端口数据互不相通。
- JSON v2 包含会话与历史，继续接受 v1；导入上限 10MiB，长时间保存全文版本会增加备份大小。
- 首次使用 AI 需同意向 DeepSeek 发送当前文章、相关版本与消息；本机保存不表示内容不会离开设备。
- 断网时已打开页面可继续文字编辑，不承诺离线首次加载或离线语音识别。
