# 产品边界

## 当前产品形态

岁月有声面向有阅历、有判断、有文字表达意愿的退休人群，帮助作者从经历与当下议题形成自己的文章。**小程序为唯一用户端，后台为对应运营端。** H5 是已退役的早期试验，专属源码与资料归档，不再参与后续功能、验收或账号同步设计。详见[维护范围](CLIENT-SCOPE.md)。

## 已实现与仍在收尾

- 小程序“热门 / 文章 / 我的”：人工精选话题、直接写作、文字与语音、作品列表、回收站、备份。
- 每篇作品一个小文会话；访谈是开关，不是另一个助手。收起保持模式，结束访谈统一请求整理；候选需用户采用才改正文。问候、原始素材、AI 建议和已采用正文分层保存。
- 无话题时不显示空主题卡片，小文先问想聊什么；开启不自动调用模型。等待、失败、重试与正文状态分开。
- 本地文件聚合、版本、修订冲突保护和 JSON v5；接受 v1–v4，导入创建副本，不覆盖旧作品。
- 微信临时 code 建立最小内部身份与业务会话；尚无用户可见账号管理、云端作品或同步。身份失败不阻塞本机文字写作。
- 运营后台负责话题编辑、AI 候选审核、不可变修订、五席排期、审计和用量监控。后台管理账号不是用户账号。

上述实现不等于所有边界已验收。当前小文保存前跨页、改文确认、撤销及版本恢复等债务见[当前流程待办](XIAOWEN-FLOW-REVIEW.md)；真实模型、键盘和新 AppID 验收仍单列。

## 数据与交互原则

正文、用户原话和来源事实不能被模型建议冒充。常规优化保留事实和原意，文风调整不能擅自编造人物关系、事件、数字或对话。只有显式采用修改正文；恢复和撤销保留历史。

“已保存”仅代表本机写入成功，不代表云备份或永久安全。换设备、微信、AppID 或清理数据可能使本地作品不可见。JSON 明文备份由用户保管，导入上限 10MiB；不清空旧 H5 的浏览器数据，旧备份仍可主动导入小程序副本。

录音在用户操作和授权后启动，不保存原音；小文输入中的识别文字可编辑，用户明确发送后才调用模型。发送给 DeepSeek 的正文、相关历史、话题与材料需知情同意。AI 结果不逐条堆叠旧核对标签；预览与对外导出保留相应来源说明，待采用不标作已经应用。

## 下一阶段与非目标

下一阶段拟完善小程序账号、私有云端作品和同账号跨设备续写，尚需单独规格与实施；本次归档不表示已实现或授权上线。先收稳本地保存、救援、冲突与恢复。

不做 H5 用户端、H5 账号绑定或小程序/H5 实时同步；不把源码里保留的后端兼容路径理解为另一条产品线。不做公开作品社区、多人协作、原音收藏或自动采用 AI。

正式 AppID、主体/域名/隐私材料及聚焦真机联调待补。借用 AppID 不允许上传或发布，账号与 token 不自动迁移。后台和小程序接口仍由既有服务器维护；退役 H5 不授权停止线上站点或删除数据。
