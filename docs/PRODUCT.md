# 产品边界

岁月有声帮助长辈把想说的话写下来，不限于回忆，也可以是诗歌或生活随笔。

已实现：文字与段落编辑、本机自动保存及恢复、回收站、TXT 与 JSON 备份、腾讯云实时语音；DeepSeek V4 Flash 常规优化、润色文笔、文章追问和对话式改文。小文会话支持按住说话转成可编辑文字，检查后仍由用户点击发送。

常规优化整理通顺、分段、用字和标点；润色文笔改善用词、描写与节奏，两者都要求保留事实和原意。点击快捷优化后进入文章会话，小文先输出修改说明和独立的待应用状态；用户再查看候选全文与原文并决定应用或放弃。AI 可能出错，用户仍需核对。没有实际变化时明确提示保留原文。标题不自动改写。

每篇文章有独立会话和版本：编辑停顿、AI 操作、修改说明、采纳/放弃和恢复可追溯，刷新仍保留。界面称为“修改记录”，按来源、分钟时间和字数展示，正文为空的起始记录不显示但仍保留在底层。优化页底部的输入外观入口只负责进入会话，实际输入区统一使用“发送”：同一次请求会根据文字回答问题，或按明确要求生成完整候选；不明确时先用短句询问。候选确认前不改正文，采用后可撤销。修改说明是小文的回答内容，待应用、已应用和未采用只表示候选状态，状态变化不会覆盖说明。优化菜单不再提供重复的“查看对话记录”，会话入口下方只保留整行“修改记录”；会话页顶部也可进入修改记录。从文章优化进入会话时，关闭会话先回到保留的优化菜单；从编辑器“聊天”直接进入时，关闭会退出文章助手。

对话调整可按明确要求改写、删除、重排内容，或加入本轮由用户明确提供的事实。文风要求可以合理改变修辞、节奏、情绪色彩和不影响核心事实的氛围表达，但不得擅自改变人物关系、谁做了什么、时间地点、数字、对话和事件结果，标题不自动修改。模型仍可能违反要求，预览会提示重点核对，不提供自动事实保证。正文最多 12000 字，较长历史会选取相关部分发送，全部已存版本仍可在本机查看。不能找回开始记录以前已丢失的文字。

待开放：精简内容、扩写内容、添加配图与自动来回的语音聊天。旧模拟源码仅保留独立测试，不作为正式入口或失败兜底。

本期不做：账号、跨设备同步、云端文章、无访问保护的公开服务、原音收藏、Word/PDF 导出。2026-08-30 起允许在固定 HTTPS Origin 和反向代理访问保护下进行少量同事的临时公网测试；这不是正式开放，也不改变产品的数据模型或功能范围。

## 保存语义

- 已保存只表示 IndexedDB 写入成功，不表示云备份或永久安全。
- 自动写入正文和未完成编辑；回收站不自动清空。
- 无标题作品用“未命名作品”；纯空白新建不出现在作品列表。
- 备份恢复为新副本，不覆盖；不同浏览器、域名、协议或端口数据互不相通。
- JSON v2 包含会话与历史，继续接受 v1；导入上限 10MiB，长时间保存全文版本会增加备份大小。
- 首次使用 AI 需同意向 DeepSeek 发送当前文章、相关版本与消息；本机保存不表示内容不会离开设备。
- 断网时已打开页面可继续文字编辑，不承诺离线首次加载或离线语音识别。

## 交付

唯一正式源码位于当前仓库根目录，本机路径见开发说明；项目统一称“岁月有声”或“正式版”，远程为用户指定且允许 Public 的 oldman 仓库。已停用本地 GPT Sites 发布接入，不修改远端站点。本机开发仍固定 localhost:3001；受控公网测试固定为 `https://suiyue.maicong.chat`，使用独立 IndexedDB，不自动上传或迁移 localhost 文章。真实手机录音与键盘必须在该可信 HTTPS 环境另行记录，桌面模拟或合成音频不能替代。
