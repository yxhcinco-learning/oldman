# 产品边界

岁月有声帮助长辈把想说的话写下来，不限于回忆，也可以是诗歌或生活随笔。

## 核心定位与议题写作

核心切入人群是有阅历、有判断、有文字表达意愿的退休知识人群，尤其是教师、医生、科研、文化及其他事业单位背景的退休者。他们通常不是不会写，而是需要持续获得值得写的议题、可信材料和适合自己的表达起点；产品应像尊重作者经验的内容编辑部与写作工作台，不以教学或代写姿态替代用户观点。

产品以少量精选的当下事件、周期主题和慢议题激发写作，不建设无限新闻流。首页用带图标和文字的固定底部导航分开“热门”“文章”“我的”，默认先展示热门：热门页提供经审核的话题，文章页继续写作，我的页只放真实的作品与备份入口，不伪造账号体系；内容区顶部不再重复导航。文章页的无箭头“开始写作”固定在主导航上方，不随作品列表滚动下沉。每个话题呈现摘要、更新时间、可选来源和相关切面；来源为空时整个来源区不显示，不用替代说明填充。前台不展示“为什么值得写”等内部编辑判断，也不把写作任务直接交给用户。用户可选择“直接写”，把事件作为可收起的文章背景；也可选择“接受小文采访”，先看到简短身份与方式说明，再在同一消息流中一次回答一个问题，最后明确请求整理成待确认文章。小文是统一角色，采访是工作模式，不恢复与小文并列的第二个助手；背景事实、用户观点、采访回答、AI 候选和已确认正文保持区分。

## 当前范围

已实现：SQLite 持久化的人工精选热门话题、“直接写”与“接受小文采访”两条入口、可折叠事件背景和显式话题版本更新；首页五席完全按编辑排期展示，可少于五条，不自动补位或再次混排。首次采访开场不调用 AI，完全未留下内容时返回热门且不生成空作品，有回答或进行中请求时进入文章并保留状态；当前页文字编辑、语音输入、本机保存恢复、回收站、TXT/JSON 备份；DeepSeek V4 Flash 文章问答、改文、优化及采访整理。话题数据库不可用时热门失败关闭，但不阻塞已有作品或普通写作；聊天回答先作为本机材料保存，只有用户明确点击整理并确认候选后才进入正文。

同仓库提供不出现在用户导航中的内部话题后台 `/admin/topics`。单一编辑可用文字、链接或两者作为引子，选择是否联网生成一套候选，也可完全手工建稿；AI 候选只能保存待审，必须经编辑修改确认后才能立即或定时发布。后台维护不可变修订、五席排期、生成记录和非敏感审计，并提供只读的当前进程运行监控；发布后更正创建更高修订，紧急下线不改写历史。H5 只上报七类无属性的低频匿名事件，用于聚合判断功能使用与在线请求状态，不形成用户轨迹或上传作品。本轮只交付本地实现与未来部署配置，未连接、更新或开放受控服务器后台。

同仓库现已提供原生 TypeScript 微信小程序客户端，尽量保持上述“热门 / 文章 / 我的”、写作、采访、小文、版本和备份语义。小程序后台用微信临时 code 建立最小业务会话，但不出现登录/注册页，也不请求手机号、头像或昵称；登录、AI 或语音不可用时，本机文字写作仍可继续。借用 AppID 只用于本机开发/体验，正式 AppID 下的身份与本地数据必须重新验证，作品迁移只走用户主动 JSON 导入。

编辑器底部以一个小按钮在语音与文字输入间切换：文字态显示麦克风，语音态显示键盘，点击只切换输入方式，不自动开始录音。语音舞台空闲时可整体收起，正文单击恢复语音、快速点击两次或触屏长按切到当前页文字输入，切换后的插入光标落在第二次点击或按住的字符位置；标题在页头显示，点击后用普通文字输入弹窗编辑，确认才写回且不改变正文语音/文字模式。小文会话和话题聊天均支持点按语音输入，已经显示的识别文字继续可编辑，仍由用户显式发送。

常规优化整理通顺、分段、用字和标点，并把无实际语义的口语填充、重复连接和松散句式改为自然书面表达；它允许必要的换词和句式调整，但不做文学化润色或以缩短篇幅为目的的精简，有意义的方言、直接引语、情感和叙述者个性仍需保留。润色文笔改善用词、描写与节奏，两者都要求保留事实和原意。点击快捷优化后进入文章会话，小文先输出只包含本轮实际差异的修改说明和独立的待应用状态；明确“未变”或把同一句改为自身的项目不会列作修改。用户再查看候选全文与原文并决定应用或放弃。AI 可能出错，用户仍需核对。没有实际变化时明确提示保留原文。标题不自动改写。

小文是编辑器中的单一、用户主动触发的文章伙伴，不等同于此前另行规划的“聊天”功能；本期只是移除当前没有实际能力的聊天占位入口，并把文章相关能力直接放进小文。点击叶片“小文”直接打开文章会话，不再经过优化菜单。会话首页暂不提供任何预设快捷指令，用户直接用文字或语音说明想问什么、想怎么改，再点击“发送”。同一次自由输入请求可以只回答，也可以按明确要求生成完整修改稿；修改稿仍须用户查看并确认后才进入正文。

每篇文章有独立会话和版本：编辑停顿、AI 操作、修改说明、采纳/放弃和恢复可追溯，刷新仍保留。界面称为“修改记录”，按来源、分钟时间和字数展示，正文为空的起始记录不显示但仍保留在底层。小文使用一个约占七成可视高度、受 Visual Viewport 约束的稳定聊天面板，不抢输入焦点，也不提供展开/收起尺寸按钮。消息独立滚动，自由输入、语音与“发送”固定在底部；短屏或系统键盘优先压缩消息区，不能遮住输入。会话输入区空内容固定一行，不受提示词长度影响，输入后随文字增长到限定高度；同一次自由输入请求会根据文字回答问题，或按明确要求生成完整候选，不明确时先用短句询问。候选确认前不改正文，采用后可撤销。修改说明是小文的回答内容，待应用、已应用和未采用只表示候选状态，状态变化不会覆盖说明。修改记录从页头48px图标进入。

关闭或 Escape 只把小文收起，并把焦点还给编辑器入口；当前作品未发送的输入保留在内存，进行中的请求继续。收起期间入口以文字和非颜色状态显示“正在处理 / 有新回复 / 需要处理”，重新打开后清除入口提醒但保留真实会话、失败和候选。只有用户点击“取消请求”、离开当前作品或页面销毁才终止请求。未发送输入不写入 IndexedDB、备份或网络，离开作品即清空。

对话调整可按明确要求改写、删除、重排内容，或加入本轮由用户明确提供的事实。文风要求可以合理改变修辞、节奏、情绪色彩和不影响核心事实的氛围表达，但不得擅自改变人物关系、谁做了什么、时间地点、数字、对话和事件结果，标题不自动修改。模型仍可能违反要求，预览会提示重点核对，不提供自动事实保证。正文最多 12000 字，较长历史会选取相关部分发送，全部已存版本仍可在本机查看。不能找回开始记录以前已丢失的文字。

本期不做小文主动读取内容后自动“捧哏”、悬浮头像、自由拖动、后台主动弹出、自动来回语音聊天，也不展示精简、扩写、配图等未来能力占位。以后增加能力需先验证触发价值、打扰程度和事实风险。旧模拟源码仅保留独立测试，不作为正式入口或失败兜底。

本期不做：用户端可见注册或密码账号、跨设备同步、云端文章、无访问保护的公开服务、原音收藏、Word/PDF 导出。内部话题后台使用独立单管理员账号，不属于用户账号体系。服务端保留小程序最小微信身份与可撤销会话，以及编辑发布的话题、排期、后台会话散列和审计；仍不保存用户作品。2026-08-30 起允许在固定 HTTPS Origin 和反向代理访问保护下进行少量同事的临时公网测试；这不是正式开放，也不改变作品本地优先的数据模型。

## 保存语义

- 已保存只表示 IndexedDB 写入成功，不表示云备份或永久安全。
- 自动写入正文和未完成编辑；回收站不自动清空。
- 无标题作品用“未命名作品”；纯空白新建不出现在作品列表。
- 备份恢复为新副本，不覆盖；不同浏览器、域名、协议或端口数据互不相通。
- JSON v4 包含议题快照、采访素材、会话、历史及按会话来源校验的 AI 辅助披露，继续接受 v1/v2/v3；导入上限 10MiB，长期保存全文版本会增加备份大小。
- 首次使用 AI 需同意向 DeepSeek 发送当前文章、相关版本与消息；话题聊天还会发送保存的话题背景和采访回答。本机保存不表示内容不会离开设备。
- 小文回答与候选持续显示“AI 辅助生成 · 请核对”；只有明确应用的候选才让作品保持 AI 辅助历史披露，未采用候选不标记正文。对外 TXT/复制带可见说明，用户手写正文和采访回答不被笼统冒充为模型输出。
- 断网时已打开页面可继续文字编辑，不承诺离线首次加载或离线语音识别。

## 交付

唯一正式源码位于当前仓库根目录，本机路径见开发说明；项目统一称“岁月有声”或“正式版”，远程为用户指定且允许 Public 的 oldman 仓库。已停用本地 GPT Sites 发布接入，不修改远端站点。本机开发仍固定 localhost:3001；受控公网测试固定为 `https://suiyue.maicong.chat`，使用独立 IndexedDB，不自动上传或迁移 localhost 文章。当前功能及 Android 实际使用已由产品负责人确认；iOS 未验证且不作为本次归档门槛。正式小程序 AppID 到位后仍需针对新的身份、本地存储与平台配置边界做 Android 聚焦复核，桌面模拟或合成音频不能替代。
