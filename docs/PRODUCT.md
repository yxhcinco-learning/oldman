# 产品边界

岁月有声帮助长辈把想说的话写下来，不限于回忆，也可以是诗歌或生活随笔。

已实现：文字与段落编辑、本机自动保存及恢复、回收站、TXT 与 JSON 备份、腾讯云实时语音；DeepSeek V4 Flash 常规优化、润色文笔、文章文字追问和对话式改文。

常规优化整理通顺、分段、用字和标点；润色文笔改善用词、描写与节奏，两者都要求保留事实和原意。点击快捷优化后进入文章会话，小文先输出修改说明和独立的待应用状态；用户再查看候选全文与原文并决定应用或放弃。AI 可能出错，用户仍需核对。没有实际变化时明确提示保留原文。标题不自动改写。

每篇文章有独立会话和版本：编辑停顿、AI 操作、修改说明、采纳/放弃和恢复可追溯，刷新仍保留。优化页底部的输入外观入口只负责进入会话，实际输入区由用户明确选择“问小文”或“调整文章”：前者可回答“某段去哪了”并引用旧版本，不改正文；后者按自然语言要求生成完整候选，确认前不改正文，采用后可撤销。系统不自动猜测意图。修改说明是小文的回答内容，待应用、已应用和未采用只表示候选状态，状态变化不会覆盖说明。

对话调整可按明确要求改写、删除、重排内容，或加入本轮由用户明确提供的事实。文风要求可以合理改变修辞、节奏、情绪色彩和不影响核心事实的氛围表达，但不得擅自改变人物关系、谁做了什么、时间地点、数字、对话和事件结果，标题不自动修改。模型仍可能违反要求，预览会提示重点核对，不提供自动事实保证。正文最多 12000 字符，较长历史会选取相关部分发送，全部已存版本仍可在本机查看。不能找回开始记录以前已丢失的文字。

待开放：精简内容、扩写内容、添加配图与语音聊天。旧模拟源码仅保留独立测试，不作为正式入口或失败兜底。

本期不做：账号、跨设备同步、云端文章、公开服务、原音收藏、Word/PDF 导出。

## 保存语义

- 已保存只表示 IndexedDB 写入成功，不表示云备份或永久安全。
- 自动写入正文和未完成编辑；回收站不自动清空。
- 无标题作品用“未命名作品”；纯空白新建不出现在作品列表。
- 备份恢复为新副本，不覆盖；不同浏览器、域名、协议或端口数据互不相通。
- JSON v2 包含会话与历史，继续接受 v1；导入上限 10MiB，长时间保存全文版本会增加备份大小。
- 首次使用 AI 需同意向 DeepSeek 发送当前文章、相关版本与消息；本机保存不表示内容不会离开设备。
- 断网时已打开页面可继续文字编辑，不承诺离线首次加载或离线语音识别。
