# 热门话题与小文采访验收

日期：2026-08-31。状态：本轮实现与桌面浏览器回归完成；OpenSpec 保持活动，等待目标用户试用和 iOS/Android 真机证据。

## 当前实现

- 首页固定底部按“热门 / 文章 / 我的”显示带图标导航，默认进入热门，内容区顶部不重复页签；文章与五张热门话题卡不再堆在一页，“我的”只提供作品与备份入口。
- 文章页的无箭头“开始写作”位于独立底部操作区，固定在主导航上方，不随作品列表滚动下沉。
- 21条人工审核话题覆盖近期、时令和持续关注内容。标题改为内容式表达，详情只显示摘要、更新时间、“大家也在关心”和消息来源，不显示内部编辑判断或任务式文案。
- 详情提供“直接写 / 接受小文采访”。前者保存可折叠背景但不插入正文；后者进入同一小文面板中的单线程聊天，先显示不调用 AI 的简短开场。
- 采访只显示消息、后续当前问题旁的“换个问题”、固定文字/语音输入和单一“发送”。回答先本机保存，再自然进入下一问；完全无内容关闭返回热门，有回答或进行中请求关闭进入文章，已有回答后才出现次级“整理成文章”。
- 小文面板不再有尺寸切换按钮；消息区滚动、输入区固定，候选仍须预览和明确采用后才写入正文。
