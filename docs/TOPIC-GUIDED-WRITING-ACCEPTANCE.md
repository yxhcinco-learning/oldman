# 精选议题与小文采访 · 实施验收

日期：2026-08-31。状态：功能与自动化实现完成，OpenSpec 保持活动，等待目标用户试用和真机/完整浏览器证据。

## 已实现

- 首批21条人工审核议题，覆盖近期、时令和慢议题；首页混排最多5条，详情保留摘要、更新时间、来源与可选角度。
- “直接写”只保存可折叠事件背景，不生成提纲、不插入正文；议题更新必须比较并显式采用，离线保留原快照。
- “让小文问问我”进入同一小文身份的采访模式：一次一问，文字/语音回答先存为来源明确的素材，支持暂停、恢复、换题和回到普通文章。
- 只把勾选素材交给“整理成文章”；结果先成为候选，继续使用预览、放弃、应用、撤销和版本记录。
- IndexedDB 与 JSON 升至 v3，继续接受 v1/v2；议题快照、采访素材、会话和正文保持分离。

## 自动化与构建证据

- `npm run check`：24个测试文件、230项测试全部通过；包含类型、Lint、OpenSpec严格校验和模块边界检查。
- `npm run build`：Vinext 五阶段生产构建通过。
- 只读网关检查：`/api/topics?limit=5` 返回5条审核议题；抽查首条含2个来源、3个角度。
- 自动化覆盖成功、失败、取消、离线、议题更新、存储冲突、v1/v2/v3备份、采访暂停恢复、未保存回答保留和候选应用。所有 AI 传输均为本地测试替身。
- 敏感信息与任务差异检查通过；未推送、未部署，未调用 DeepSeek、腾讯 ASR 或麦克风，真实计费请求为0。

## 尚缺证据

- 浏览器工具在网关重启前验证了“议题不可用时，5篇已有作品和普通写作仍可访问”；重启后控制层因 localhost URL 安全策略拒绝继续，故不把该结果记为360×640、390×844、430×932和1280×900的完整回归。
- 尚未执行目标退休知识人群的小规模卡片对照试用，也未获得本次议题/采访路径的 iOS Safari 与 Android Chrome 真机键盘、听写、来源链接和恢复证据。
- 用户未明确授权真实话题/AI付费联调，因此未执行。上述证据补齐前不归档 `add-topic-guided-writing`。
