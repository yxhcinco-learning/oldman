# 热门话题与小文采访验收

日期：2026-08-31。状态：本轮实现与桌面浏览器回归完成；OpenSpec 保持活动，等待目标用户试用和 iOS/Android 真机证据。

## 当前实现

- 首页固定底部显示“文章 / 热门 / 我的”三项导航，内容区顶部不重复页签；文章与五张热门话题卡不再堆在一页，“我的”只提供作品与备份入口。
- 21条人工审核话题覆盖近期、时令和持续关注内容。标题改为内容式表达，详情只显示摘要、更新时间、“大家也在关心”和消息来源，不显示内部编辑判断或任务式文案。
- 详情提供“自己写 / 和小文聊聊”。前者保存可折叠背景但不插入正文；后者进入同一小文面板中的单线程聊天。
- 采访只显示消息、当前问题旁的“换个问题”、固定文字/语音输入和单一“发送”。回答先本机保存，再自然进入下一问；关闭即暂停，已有回答后才出现次级“整理成文章”。
- 小文面板不再有尺寸切换按钮；消息区滚动、输入区固定，候选仍须预览和明确采用后才写入正文。

## 验证证据

- 专项回归：`tests/topics-ui.test.tsx`、`tests/ui.test.tsx`、`tests/design-baseline.test.ts` 共44项通过；`npm run check` 的24个测试文件、231项测试、类型、Lint、OpenSpec严格校验和模块边界检查全部通过，`npm run build` 的五阶段生产构建通过。
- 四尺寸实页回归覆盖三页导航、话题详情、自己写背景和小文采访；360×640、390×844、430×932、1280×900 均为 `scrollWidth = clientWidth`。
- 三项底部导航按钮均高52px，固定贴合可见底边；内容区不存在旧顶部页签。采访面板高度依次约461、608、620、620px，输入区底部始终距可见底边12px，发送按钮高48px，尺寸切换按钮为0。
- 实页只请求话题列表和两次话题详情，没有请求 `/api/ai`；未点击语音，不调用 DeepSeek、腾讯 ASR 或麦克风，真实计费请求为0。
