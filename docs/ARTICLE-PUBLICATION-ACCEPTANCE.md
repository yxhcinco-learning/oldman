## 数据与恢复边界

auth.sqlite 升到 schema 3 后，旧 schema 上限的网关不得回滚启动；旧备份也不得覆盖新增用户名归属、投稿或作品。`sqlite-db.mjs restore` 遇到已有 schema 3 数据库直接拒绝覆盖，需要保留当前库并单独制定恢复步骤。正常备份仍可验证；当前线上 schema 2 未被本次本地测试更改。

JSON v6 继续只备份文字、素材与会话，不含封面或投稿身份；导入创建私有副本，重新选择封面后才能投稿。永久删除清除在线投稿正文与专属图片，审计不保留正文。已发送微信卡片的缓存无法回收，但旧链接不能取得已撤下正文。
