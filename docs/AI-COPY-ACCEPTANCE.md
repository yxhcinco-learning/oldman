# 文章助手文案精简验收

日期：2026-08-30

## 调整原则

本次删除能从标题、按钮和状态直接看出的重复解释，并将面向长辈的技术词换成日常说法。没有改变 DeepSeek 提示词、接口、请求次数、会话数据或正文写回流程。

已删除会话输入区的按钮说明、重复的会话标签和教学式空态；生成与保存状态、放弃结果、结果页说明和长记录裁剪提示改为短句。首次 DeepSeek 授权、失败补救、正文冲突、事实核对、恢复覆盖和记录未发送范围继续显示。

修改记录页采用以下取舍：

- “文章版本记录”改为“修改记录”，“字符”改为“字”；
- 时间保留到分钟，不显示秒数；
- 保留来源、时间和字数，便于区分相近记录；
- 正文为空的“开始记录”卡片不展示，底层数据不删除；
- “确认恢复此版本”等技术说法改为“恢复这份内容”。
