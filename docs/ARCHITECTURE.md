# 架构与决策

## 当前维护结构

小程序唯一用户端，网页仅运营后台。H5 用户端物理归档至 archive/h5，所有活跃模块不得引用它。完整历史 ADR 见[退役前快照](archive/h5/ARCHITECTURE.md)，其中双端与浏览器细节不再约束后续开发。

| 层 | 实现与依赖 |
| --- | --- |
| 用户端 | apps/miniprogram，原生 TS/WXML/WXSS，依赖共享核心与微信适配器 |
| 运营端 | app + features/topic-admin，React/Vinext；独立基础样式，根路由进入 /admin/topics |
| 服务端 | server，Fastify/Node；直接引用 packages/core，不依赖 H5 的 features/lib |
| 共享层 | packages/core，领域模型、会话编排、备份、协议；禁止 DOM、Node、wx |
| 归档层 | archive/h5，历史源码/测试/预览；排除类型、Lint、测试和发行归档，无活跃依赖 |

## 数据与事务

小程序本地聚合 schema v3 保存 Work、Draft、ArticleSession、WritingState 和独立云元数据，兼容 v1/v2；串行写入、预期 revision、临时文件校验替换及崩溃恢复保护原文。正文版本、原始消息、素材、更正关联和候选采用状态分开。JSON v6 兼容 v1–v5，导入副本重映射所有 ID 和引用，不能把导入当同步。收到回复的结算先写每篇独立 `.result.json` 恢复记录；聚合失败保留记录及内存副本，重试只写本机，revision 冲突不覆盖。聚合已提交而索引失败时重试幂等；旧会话不能回写覆盖新回复。全部磁盘写入失败只保证当前进程内可救援。撤销用可选 revertedVersionId 关联恢复版本，不删除曾采用记录；历史恢复追加版本并保留当前手改快照。

服务器 auth.sqlite 保存最小内部用户、(app_id, openid) 身份与会话散列；topics.sqlite 保存运营编辑内容与审计；usage.sqlite 保存匿名日用量与预留。auth.sqlite 升级 schema 3，身份、正式账号会话、私有资料与作品、唯一用户名及发表审核分模块，共享 SQLite 事务串行接管与作品写入。作品归属从有效会话取得，后台管理员无读取权限。快照独立云 version、账号 sequence、不可变 operationId 回执及永久删除标记防止覆盖和复活。头像通过 sharp 限像素解码、缩放为 256px JPEG、去元数据后私有存储。

列表加载同样会重建索引和清理恢复记录，必须与聚合读写、云确认共用仓储串行队列；不能读取原子替换中的中间状态。微信文件清理只忽略明确的不存在错误，容量、权限等失败继续进入恢复流程。页面使用中文业务错误，底层路径及协议诊断不得直接渲染。

## 账号同步

客户端以 launch 品牌页分流：恢复已有会话后进入热门，无会话进入 login 微信授权页。只有点击按钮才换码，首次账号由服务端建立；恢复会话使用单飞读取，避免启动与登录页并发把未读完的会话当游客。在线入口先落盘，再把固定来源仓储与应用内路由交给登录返回模块；成功按游客 claim 重映射作品 ID，账号变化则回作品列表。所有产品页面在读取内容前经过统一登录门禁，直接路径和返回栈不能绕过；登录页只保留登录按钮和隐私入口。已有账号的临时离线不视作退出。返回不恢复网络任务或录音；独立根作品页提供返回文章列表的兜底。

主动登录签发 30 天会话并撤销旧会话；普通续期只延长有效 token。过期、退出或接管后不自动调用 wx.login；账号启用后旧换码入口不能抢占。AI、语音和云同步统一传播失效原因，语音票据和连接也绑定原会话。

游客文件沿用旧目录，已验证账号使用独立目录和固定服务实例。首次读取云目录后，把游客作品（含回收站）写入持久认领意图，再复制到账号目录并标记完成；失败可重试，绑定后不能随登录变更。ID 冲突重新分配，旧文件不删除。每次本地提交后冻结上传操作，后续修改另记待同步；确认丢失以同一操作重试。恢复冲突先持久化完整本机副本，再安装远端；恢复副本仅在用户另存时入云。

打开、返回前台及网络恢复先验证账号和云快照，落盘后才解锁云作品。编辑页待保存输入在同步前刷盘；迟到结果留在原实例。未发送小文输入进入持久 WritingState，恢复不重发模型，不恢复录音/键盘/加载任务。

前台恢复先保存已有输入，再判断是否存在本机修订、已保存结果或云版本。尚未落盘的新稿保留内存标识和输入方式，不按作品文件重开；已有作品即使正文为空仍核对版本，文件缺失不能降级为新稿。读取失败单独记录原目标并锁定编辑，重新打开执行读取；保存失败仍执行保存重试。

## 作者工作区与发表页面

我的主页通过 `author-articles` 组件的摘要模式展示一篇最近草稿和两篇其他文章，独立 works 页面复用组件完成搜索、状态筛选与每次20篇分页管理；回收站继续使用该页面的独立模式，不再把完整列表重定向个人中心。资料与设置由主页管理，作品入口依据草稿、待审、已发表及未提交修改选择编辑、审核预览或公开阅读。公开版比较只读取作者自己的已提交快照，按可见文章分批获取并缓存不可变投稿 ID；不向公共接口增加私有稿或内部账号字段。

发表页区分设置、可选只读预览、全屏裁切、审核预览和提交结果。设置不展开正文，预览只组合当前已确认正文、真实署名和封面；直接提交内部先同步并准备最新快照，再固定操作ID执行服务端版本/署名校验，未知结果原样重试，不能重新准备后重复投稿；审核页从作者投稿接口读取冻结内容，不能用后来修改的工作稿代替。封面侧文件保留裁切前的 `cropBackup`，取消还原原有封面，重启可以恢复未完成裁切；两种用途分别确认后才清除备份并准备投稿。旧侧文件缺少此字段时按空备份读取，不改变正文聚合或 JSON v6。

删除确认捕获来源服务实例、作品 ID 和修订，原生弹窗成功确认且账号仍一致后才调用既有删除事务；弹窗失败和服务错误均可重试。原生按钮文案遵守微信长度上限，空正文不会被当作无法删除的假数据。

## 小文与语音

小文由三个独立状态协作：

| 状态 | 职责 |
| --- | --- |
| conversation.mode | 持久化访谈开关；收起不退出 |
| turn | 单轮请求等待、失败、停止或结果；不等同于访谈状态 |
| 正文版本与采用记录 | 生成不等于采用；撤销追加恢复版本，不删除会话历史 |

conversation.mode 是持久模式唯一来源。共享 prepareDialogue / settleDialogue 编排原始消息、模式事件和素材；protocolVersion=2 的 dialogue 在一次模型请求中完成语义判断与回复，不由客户端关键词路由。无话题开场由共享核心派生；短问候不自动成为素材。结束按钮先存普通模式再整理，自然语言切换只在有效结果保存后生效；候选采用才写正文。待确认修改经反问与纠正仍保留，新要求替换，明确 cancel-edit 只撤回要求。近期与早期相关材料在同一预算内按原话关联选入。具体已验证边界及剩余真机事项见[可靠性验收](archive/phase-one/XIAOWEN-RELIABILITY-ACCEPTANCE.md)。

小程序使用 RecorderManager、wx.request、wx.connectSocket；语音票据短时且单次消费。网关直连腾讯云，密钥仅服务端；AI 直连 DeepSeek。限额在上游调用前预留，未知结果保守结算，不自动重试计费调用。

服务端原 /api/ai、/api/speech 与匿名事件路径暂保留为独立兼容协议和回归接口；其实现已不依赖 H5。保留接口不代表保留 H5 产品，也不允许绕过既有 Origin、鉴权、限流和用量边界。未来删接口须单独盘点调用方和部署配置。

整理短材料仅重排和润顺已有表达，不把助手追问或未提供的伤情/心理补入作者经历；提示词明确逐句来源核对，固定联调与人工语义复核分别留证，不宣称模型可被提示词完全消除幻觉。

## 运营与部署

发表阶段在 auth.sqlite schema 3 独立存放唯一用户名归属、发表设置、处理后的图片、不可变投稿、公开版本及审计；与私有作品共用事务但不共用公开投影。后台只可读明确投稿内容，不能取得 WorkSnapshot、未投稿封面或会话。原删除事务同时撤销待审和公开内容；恢复不发表。小程序使用账号隔离的独立发表侧文件保存封面及裁切，不改正文聚合 v3 或 JSON v6。当前实施及验证状态见 STATUS，不据此推断线上已升级。

后台继续独立管理员会话、HttpOnly/Secure/SameSite Cookie、Origin、CSRF 和修订并发保护；候选不绕过人工审核。后台预览是运营内容预览，不复用或启动 H5 应用。

保留现有 Node 24、TypeScript、React/Vinext 和 npm 工具链用于管理台与服务，删除 H5 独有 IndexedDB/Tailwind 依赖。服务使用 Nginx + 两个 systemd 单元、回环 3011/3012 和 release 外三库。网关可独立部署，安装 unit 固定 release 路径；网页与 current 可保持其他版本，不因本地根路由变化自动退役线上 H5。分别按[部署记录](DEPLOYMENT.md)核对两服务版本及回滚目标，不用current推断网关版本。

新增依赖边界扫描禁止活跃代码回引归档与旧兼容层；check/build 保留后台、服务、共享核心和小程序验证，不安装归档依赖、不运行历史 H5 UI 测试。Git archive 排除 archive/ 与 docs/archive/。
