# 修改记录页头统一 · 本地验收（2026-08-30）

## 范围与结论

文章优化首页原先在小文会话入口下方单独显示整行“修改记录”，与会话页已经采用的页头入口不一致，也额外占用手机纵向空间。本轮把优化首页同步为页头图标操作，删除内容区整行入口和废弃样式；修改记录内容、版本恢复、来源感知返回、文章会话和 IndexedDB 数据均未改变。

现行行为：

- 文章优化首页与小文会话页都在页头提供48px的书本图标按钮，完整可访问名称为“查看修改记录”。
- 优化首页内容区以小文会话入口结束，不再渲染单独的修改记录行，也没有重复的“查看对话记录”。
- 从优化首页进入修改记录后，“返回上一级”回到仍打开的优化首页；关闭语义保持原样。
