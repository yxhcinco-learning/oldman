## 实现与交付范围

主动微信登录、30 天单有效会话及有效会话续期、退出/过期/接管状态、可选头像昵称、私有头像解码与存储、自动私有云保存已接通。归属来自服务端认证，管理员会话不能读私有作品；已启用账号的旧客户端换码被拒绝。

本机聚合 v3 按游客/账号隔离，认领意图、云版本与固定操作持久化。打开云作品先核对最新版本，网络中断暂停新编辑并保留当前输入；本机新稿可继续写。冲突生成完整恢复稿，支持查看、另存新篇和导出。正文、版本、小文会话、素材、访谈模式和已保存待确认输入跨设备恢复，不重新执行模型任务，不保存原音。

回收站操作核对云版本，永久删除仅保留必要标记与无正文回执。JSON v6 包含写作输入，接受 v1–v5，导入创建副本，分卷每份不超过 10MiB；无法装入单份的超大单篇明确失败并保留本机内容。全部备份先补齐云端，离线标为本机备份。

Nginx 精确白名单、9MiB 作品请求与 2MiB 头像上限、可配置账号容量/数量/频率、schema 2 备份和目标 release 兼容检查已更新。启动失败不自动恢复旧库；兼容则回滚代码，不兼容保留当前库并等待前向修复。
