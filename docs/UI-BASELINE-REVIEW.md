# 已验收界面回归核对 · 2026-08-27

历史验收记录：以下测量对应当时的旧设计。用户随后批准 Echoes 全面落地，当前视觉请以 [DESIGN-SYSTEM.md](../DESIGN-SYSTEM.md) 为准。

基准：已验收设计的 Git 提交 `28fd5e4`。本轮仅修正产品化引入的 UI 偏差，不重新设计、不改数据库或语音协议，不发布。

## 差异与处理

| 位置 | 产品化偏差 | 本轮处理 |
|---|---|---|
| 作品卡片 | 额外的更多按钮与 48px 右留白挤偏时间、标题和“继续写” | 删除额外按钮及包裹层，恢复已验收的 12px 内边距和完整内容列 |
| 卡片时间/状态 | 数字月日、“本机保存”替代原有表达 | 真正修改时间生成刚刚/今天/昨天/中文日期；使用原有“已保存”，不造“整理中/已完成”状态 |
| 首页 | 回收站与体验 AI 演示额外铺在列表下；引导文案被替换 | 移除独立快捷入口，恢复已验收引导文案；已批准数据工具收进原有右上角更多 |
| 编辑器 | 新增 48px 保存状态/操作行，缩短正文 | 移除整行，保留原页头保存及四个底部控件；保存状态和失败反馈继续真实生效 |
| 单段编辑 | 副标题被去掉，字数变成存储说明 | 恢复“可以修改错字和标点”和实时字数，不回退真实编辑/自动保存 |
| 文字模式/提示 | 提示文案与已验收设计不同，反馈缺少输入模式位置类名 | 恢复文字模式提示和对应反馈位置，不新增卡片或层级 |
| 演示 | 40px 标识行容纳 48px 按钮 | 标识行与点击高度对齐；其余聊天、优化、配图、撤销结构保留 |
| 隐藏文件输入 | 键盘可落到不可见的文件按钮 | 使用原生 hidden，仅从菜单按钮打开文件选择 |
| 数据工具反馈 | 导入/管理失败提示可能被原生对话框遮挡 | 先关闭菜单，再在原有反馈位置显示结果；不增加常驻提示层 |

必要差异仅来自已批准的产品能力：空作品库、实际时间/字数、本机保存错误与权限说明、隔离演示标识，以及原更多菜单内的数据工具。它们不授权额外常驻入口。

## 核对与证据

- 完整核对首页、空白编辑器、文字模式、单段编辑、语音区域、聊天、优化抽屉/结果/撤销和退出；已验收的基础 CSS（除已移除的模拟键盘）逐字规范化后指纹一致。
- 当前浏览器 1280×720：画布宽 430px，左边距 425px；卡片内边距 12px，时间和继续写右边缘均为约 820.33px。卡片仅一个点击入口，页面无 work-menu / library-links / save-row。
- 同一尺寸下：标题高 44px；正文紧接底部输入栏，无额外工具行；麦克风中心 (640, 666)，转写预留阶段区高 138px。保留原网格和固定高度，无实时转写导致的重排改动。
- 使用临时同源 iframe 在真实浏览器渲染 360×640、390×844、430×932，截图检查首页和空白编辑器；四个控件无挤压换行，麦克风和底部区域完整可见。临时页面已移除，不作为产品入口或提交。
- 浏览器实际走通原更多菜单 → 管理作品/回收站 → 返回/关闭；检查空白文章进入聊天、单段演示编辑、自定义优化/应用/撤销/退出。演示文本未进入真实编辑器；原有真实测试作品仍为原来的 31 字、时间未变化，无新增模拟作品。
- 自动测试覆盖从收纳后的菜单复制、软删除/恢复、备份导入副本和原记录不覆盖；菜单焦点回到原入口；原生隐藏文件选择仍可由菜单触发。
- `npm run check`：83 项测试、类型、Lint、OpenSpec、边界检查通过；`npm run build` 和 `git diff --check` 通过。没有新增依赖。

本轮没有打开真实麦克风或调用腾讯云，没有清空用户数据库。响应式 iframe 和桌面截图不等于手机安全区、键盘或真实采音验收；这些仍保持原有上线前门禁。

后续 AI 修改须先对照 DESIGN-SYSTEM.md 与本记录；产品能力的批准不等于可以随意扩展界面。样式指纹仅防回退，布局和交互仍需实际页面检查。
