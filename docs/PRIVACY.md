# 数据和隐私

> 当前仅小程序为用户端，网页仅运营后台；H5 相关网络与本地存储说明是尚未停站的旧兼容边界，不是新产品能力。见 [维护范围](PRODUCT.md)。

## 账号、私有作品与备份

- 历史游客作品保留在当前微信、AppID 和设备的原文件空间。点击“微信登录”后，用临时 code 换取内部账号会话，自动上传当前尚未归属的本机作品（含回收站）；作品绑定后不随换账号迁移。无需另开云同步开关。
- 品牌开屏和独立授权登录页不自动换码；首次登录自动建号，未登录可查看登录页、隐私说明及作者已同意游客公开的审核文章、派生封面、通过评论和公开作者资料；热门、文章 Tab、创作、个人信息及互动写入仍需登录。登录页及个人中心可阅读隐私说明，原生头像、用户名编辑、微信隐私和录音授权流程保留，不以登录代替这些授权。
- 服务端保存内部用户、当前 AppID 的 OpenID、code/token 哈希、唯一展示用户名、历史名字归属及处理后的私有头像、私有作品快照、版本和必要同步回执。新云作品快照包括文章正文、历史版本、已发送的小文消息和素材、访谈模式，不包含待确认语音、段落编辑框或未发送输入，也不含原音。后台管理账号不能读取私有作品。
- 标题和当前正文均为空时，不建立文章或作品上传。待确认语音、段落编辑框及未发送输入仅保留本次编辑内存，不自动写入文章或恢复文件；进程退出后不恢复。已发送会话和收到的结果可在原账号的本机空间按原草稿 ID 独立恢复，未成文章时不作为云作品或备份文章。既有文章即使被清空仍保留，旧格式继续可读，不批量删除历史数据；旧版已上传内容和已冻结的同步操作不因本次规则自动清除。
- 用户名默认“岁月作者＋数字编号”，服务端规范化后唯一，历史名字永久归原账号保留；改名不会改变已投稿署名。头像由本人主动选择。头像最多 2MiB，服务端解码限像素、缩放和去元数据，仅保存转换后图片，读取必须有本人有效会话，无公开原图地址。不增加手机号、密码、设备列表或账号注销。
- 同一账号只允许一个有效在线会话；其他设备登录后旧会话失效，不自动抢回。退出立即停止同步、隐藏账号缓存，保留该账号未上传的恢复内容；异步结果仍归原账号。
- auth.sqlite 位于服务器 release 外的受限目录，迁移前做 root-only 备份。云端永久删除移除在线正文和会话，仅保留防复活标记；其他设备下次验证和同步时清理缓存，不承诺立即清除离线设备或历史运维备份。代码回滚不得用旧库覆盖已接收的新作品。
- JSON v6 新导出明文包含文章、已发送会话和 AI 来源，不包含当前输入框文字，也不把未成文章的会话导出为空文章；每卷不超过 10MiB，兼容 v1–v5。JSON v6 不包含封面或发表身份，导入始终新建私有副本，需重新选封面投稿，不携带账号、OpenID、凭据或同步队列。全部备份先补齐云作品，离线明确为本机备份。文件由用户自行保管，不进入代码仓库。

## 文章发表、人工审核与好友分享

作者明确点击提交审核，服务端才冻结标题、确认正文、处理后的封面、当次用户名及适用 AI 标识。阅读预览为可选操作，提交前由程序同步并核对当前内容；公共列表摘要仅截取当前已发表正文，不读取私有工作稿。小文会话、素材、候选和待确认语音保持私有；管理员只读这些明确投稿的快照，不能修改作者原文。投稿后显示“已提交审核”，所有账号均须人工通过。历史文章、详情与图片默认须登录读取；作者主动选择允许未登录阅读后才向游客提供该文章的独立公开投影，缺省或旧客户端缺少选择不扩大受众。服务端记录受众版本、同意人、时间和说明版本，关闭后正文、图片及评论立即停止向游客供给。公开头像使用系统默认头像，作者采用不可由内部身份推导的稳定公开 ID，响应不包含内部账号 ID、自选头像或未审核修改。

封面原图与裁切先保存到账号隔离的本机目录，再上传处理；本机设置与正文聚合分离。上传上限 8MiB、解码上限 4000 万像素，纠正方向、最长边缩至 2048px 并去除元数据，生成列表 1:1 与阅读/好友卡片 5:4 图片。发表快照及在线图片使用独立每账号 100MiB 配额；无引用上传七天后清理。后台不能读取未投稿封面。

改稿审核期间旧公开版继续可读；新稿通过后替换同一文章，驳回保留旧版。撤回发表、下架和删除会同时停止公开列表、详情与图片供给，旧好友链接不能继续读取正文。下架会取消待审稿，恢复回收站作品不恢复发表。永久删除清除在线投稿正文和专属图片，仅留不含正文的必要审计及删除标记。已发出的微信好友卡片缓存无法回收。

## 读者互动、关系与小花花

点赞、收藏、评论、关注和赠礼使用有效账号；收藏、关系明细、库存及领取记录只向本人提供。公开只展示默认头像、稳定公开作者标识、用户名、当前可读的已发表文章、通过评论及对应计数。互关由双方独立关注推导，昵称变化不改变关系。自己的未通过评论可见，文章作者不能读取其他人的待审内容。

评论仅接受1–300字纯文字，明确发布后进入独立人工审核；本人可删除，读者可举报公开评论，独立后台才可读取必要举报理由和审核审计。文章撤回或下架使相关公开评论不可读，永久删除清除评论正文及可能含正文的举报/审核说明。后台不得读取私有工作稿、会话或未投稿封面。

小花花每天按服务端北京时间为有效账号发3朵，余额可累计；每次本人确认才送出1朵，不能给自己送、购买、交易或兑现，作者获赠不增加可送余额。账本和固定操作回执用于余额核对与防止重试重复扣减，不含文章正文；文章撤回后不退还已送花朵。JSON备份不包含关系、评论、库存或社交回执。

评论草稿仅在本次运行内存保存，登录后仍须再次发布；送花登录后也要再次确认。取消登录不产生互动，账号切换清理原账号互动态和草稿。允许游客阅读的正文、封面及评论每次重入或返回前台核对当前权限，不能以缓存绕过受众收回；无法回收微信已缓存的好友卡片。

分享闭环只采集分享来源进入、登录意图、登录成功、服务确认互动、再次访问的固定事件与公开文章标识。匿名联结标识仅本次短期会话有效（30分钟），不使用持久设备指纹或联系人；事件去重记录最多保留7天，无身份的按日汇总最多保留90天，仅独立管理员查看汇总。事件不含评论文本、私有作品、OpenID、token或用户阅读轨迹；分享菜单打开不代表好友送达，采集失败不阻塞使用。该边界适用于本次已确认实施，线上实际版本以部署记录为准。

## 话题编辑数据

- 独立 `topics.sqlite` 只保存编辑话题、不可变修订、AI 生成计数与固定状态、五席排期、单一管理员、后台会话散列和操作审计，不保存用户文章、采访回答、原音或用户端身份资料。话题库与 release 分离，并和身份库分别备份与恢复。
- 管理员密码只以服务端 scrypt 散列配置；登录 Cookie、CSRF 和会话 token 使用随机值，数据库只保存散列。审计只记录操作者、动作、实体、时间和非敏感差异摘要，不记录密码、Cookie、CSRF、DeepSeek Key 或上游原始响应。密码轮换、退出和过期会撤销会话。
- 编辑主动生成候选时，引子文字、链接、联网开关和生成时间会经服务端发送给 DeepSeek；链接存在时模型会使用服务端 web search。系统只保存候选结果和模型/token/搜索次数/错误类别，不保存思维链。引子不得包含用户私密文章或未经授权的个人资料。
- 发布话题允许 0–5 条来源。来源为空时用户端不显示来源区域；存在来源时公开显示编辑确认的标题、发布者、URL 和日期。话题数据库失败时公开热门与后台返回服务不可用，不用静态假数据掩盖故障。

## 语音转文字

- 只有用户在正文、小文输入框或采访回答处长按语音后，客户端才调用微信隐私授权和 `scope.record` 麦克风授权。拒绝、短按、授权期间松手或切后台都不会暗中开始录音，文字输入和本地写作仍可使用。
- 当次 PCM 音频通过岁月有声服务端网关发送腾讯云实时语音识别，只把识别文字放入当前输入位置；不会自动发送小文、应用正文或保存原音文件。腾讯云侧的数据处理适用其服务设置与条款。
- 网关不接收整篇文章用于语音识别，不记录正文或音频日志；连接有时长、字节、缓冲和并发限制，结束、取消或异常时释放录音与 Socket。

## 小文与 DeepSeek

- 只有用户明确点击发送、整理或重试后，小程序才按首次同意规则显示数据去向说明；同意后，经岁月有声服务端网关向 DeepSeek 发送当前标题/正文、选取的历史版本及消息。本轮需要时还会发送该作品保存的话题背景和所选采访回答。拒绝后请求不发送，本地写作、文字输入和语音转文字仍可继续。
- DeepSeek Key 只由服务端读取，不进入客户端；本产品不记录 Key、文章或会话日志，不自动重试计费请求。明确停止会尽力中止请求，收起小文不取消，但不能保证上游已经处理的调用不计费。不要发送不希望交给外部服务的私密内容。
- 小文聊天不再逐条显示旧核对标签；候选预览与对外导出保留适当的来源说明。候选需用户明确应用才进入正文；用户原始回答、手写正文和话题来源不会被笼统标成 AI 输出。模型可能误改或补充细节，应用前必须核对。
- 一篇作品只要历史中存在已应用的完整 AI 候选，就保持保守的 AI 辅助披露；后续手改或恢复不会抹掉历史。未采用候选不会让正文导出被误标。对外复制和 TXT 会带可见说明，JSON v6 同时保存机器可读来源与用户可读说明。

## 网络、日志与旧线上兼容边界

旧线上 H5 未停站，其作品仍在原浏览器 Origin 的 IndexedDB；不自动读取、清空或上传。以下 Basic Auth 与匿名事件为兼容边界，不能据此恢复 H5 用户端建设。

- 无手机号注册或第三方分析。小程序的读者互动汇总使用独立受限入口，不发送这套旧兼容事件。保留的旧 H5 兼容调用方只为“打开应用、查看话题、开始空白/话题/采访写作、成功导入/导出备份”七类低频动作发送第一方匿名事件。请求体只有固定事件名，不含任意属性、用户/设备标识、话题/作品 ID、标题、正文、采访、搜索词、URL 或客户端时间；失败不排队、不保存、不重试，也不影响本地操作。
- 匿名事件入口保持在用户网页的 Basic Auth 后，同时接受 Nginx 按 IP 限流和应用全局限流。网关只把事件合并为当前进程内的计数；管理员“运行监控”只显示 15/60 分钟与进程累计的请求量、状态、固定错误、延迟和 token。聚合不含 requestId、IP、User-Agent、Header、原始请求或个人轨迹，服务重启即清空。
- 公网网关只在 Nginx 后提供，应用端口保持回环。代理与应用日志不得包含正文、聊天、音频、OpenID、session key、Cookie、Authorization、访问凭据、Key、签名 URL 或上游私密响应；单条安全日志只允许请求标识、固定动作、状态、耗时、token 或固定错误类别，进程内监控只保存不含请求标识的聚合。
- 用户网页继续由 Basic Auth 保护；公开已审核话题和明确列出的小程序账号、私有作品、AI、语音票据/WSS 路径绕过该浏览器认证，随后仍由 IP 限流、业务 token 或单次 ticket 保护。内部 `/admin/topics` 和管理 API 也绕过 Basic Auth，改由独立后台登录、HttpOnly/SameSite/Secure Cookie、精确 Origin、CSRF、JSON 与限流保护；用户端 Basic Auth 凭据不能替代后台登录。小程序语音 URL 的 ticket 不写入访问日志，未列出的 API 直接拒绝。
- 正式小程序上线前还需在最终 AppID 下配置并复核微信用户隐私保护指引、麦克风用途、request/socket 合法域名、第三方处理说明和 AI 生成服务标识。开发者工具中的临时 AppID 预览不代表平台审核或法律合规结论。
