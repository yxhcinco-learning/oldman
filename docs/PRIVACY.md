# 数据和隐私

## 本地作品与微信身份

- 网页端作品、采访素材、会话和历史版本保存在当前浏览器 Origin 的 IndexedDB；小程序端保存在当前微信用户、当前 AppID 与当前设备隔离的本地用户文件。两端都不是云备份，清理数据、换设备、换微信、换 AppID 或浏览器回收可能导致原数据无法读取，请定期导出 JSON 备份。
- 小程序打开时用 `wx.login` 的临时 code 建立内部业务会话，只保存内部用户、当前 AppID 下的 OpenID、一次性 code 哈希和业务 token 哈希；不请求或保存手机号、头像、昵称，也不把身份作为作品所有权或恢复密钥。服务端身份库不保存正文、采访素材、会话或备份。
- JSON v4 以明文包含作品、会话、历史版本和每篇作品的 AI 来源披露；TXT/复制包含待对外使用的正文及必要的可见 AI 辅助说明。文件由用户自行保管，不上传代码仓库；导入只创建新副本，不迁移 token 或 OpenID。

## 语音转文字

- 只有用户在正文、小文输入框或采访回答处长按语音后，客户端才调用微信隐私授权和 `scope.record` 麦克风授权。拒绝、短按、授权期间松手或切后台都不会暗中开始录音，文字输入和本地写作仍可使用。
- 当次 PCM 音频通过岁月有声服务端网关发送腾讯云实时语音识别，只把识别文字放入当前输入位置；不会自动发送小文、应用正文或保存原音文件。腾讯云侧的数据处理适用其服务设置与条款。
- 网关不接收整篇文章用于语音识别，不记录正文或音频日志；连接有时长、字节、缓冲和并发限制，结束、取消或异常时释放录音与 Socket。

## 小文与 DeepSeek

- 只有用户明确点击发送、整理或重试后，网页或小程序才显示数据去向说明；同意后，经岁月有声服务端网关向 DeepSeek 发送当前标题/正文、选取的历史版本及消息。本轮需要时还会发送该作品保存的话题背景和所选采访回答。拒绝后请求不发送，本地写作、文字输入和语音转文字仍可继续。
- DeepSeek Key 只由服务端读取，不进入客户端；本产品不记录 Key、文章或会话日志，不自动重试计费请求。关闭/取消会尽力中止请求，但不能保证上游已经处理的调用不计费。不要发送不希望交给外部服务的私密内容。
- 小文的回答和完整候选持续显示“AI 辅助生成 · 请核对”。候选需用户明确应用才进入正文；用户原始回答、手写正文和话题来源不会被笼统标成 AI 输出。模型可能误改或补充细节，应用前必须核对。
- 一篇作品只要历史中存在已应用的完整 AI 候选，就保持保守的 AI 辅助披露；后续手改或恢复不会抹掉历史。未采用候选不会让正文导出被误标。对外复制和 TXT 会带可见说明，JSON v4 同时保存机器可读来源与用户可读说明。

## 网络与日志

- 无手机号注册、遥测分析或云端作品同步。网页受控公网测试的 Basic Auth 只是入口保护；小程序业务会话只控制在线接口。不同浏览器 Origin、设备、微信用户或 AppID 的本地文章不会自动出现或上传。
- 公网网关只在 Nginx 后提供，应用端口保持回环。代理与应用日志不得包含正文、聊天、音频、OpenID、session key、Cookie、Authorization、访问凭据、Key、签名 URL 或上游私密响应；只允许请求标识、动作、状态、耗时、计数或错误类别。
- 正式小程序上线前还需在最终 AppID 下配置并复核微信用户隐私保护指引、麦克风用途、request/socket 合法域名、第三方处理说明和 AI 生成服务标识。开发者工具中的临时 AppID 预览不代表平台审核或法律合规结论。
