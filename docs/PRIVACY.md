# 数据和隐私

- 作品、会话和历史版本持久保存在当前浏览器 IndexedDB。清理数据、隐私模式或浏览器回收可能造成丢失，请定期导出备份。
- JSON 包含作品、会话和历史明文，TXT 包含文章及待确认编辑，请妥善保管，不上传代码仓库。
- 语音需用户同意与麦克风授权；音频通过岁月有声服务端网关发送腾讯云识别，腾讯云侧适用其服务设置和条款。
- 本产品不持久保存原音，不发送完整文章给识别服务，不记录正文或音频日志。
- 常规优化、润色、文字问答、对话调整、采访追问和素材整理会在首次同意后，经岁月有声服务端网关向 DeepSeek 发送当前标题/正文、选取的历史版本及消息；采访请求还会发送该作品保存的议题背景和本轮所选采访素材。DeepSeek 侧适用其服务设置与条款。不要发送不希望交给外部服务的私密内容。
- DeepSeek Key 只由服务端读取，不进入客户端；本产品不记录 Key、文章或会话日志，不自动重试计费请求。关闭/取消会尽力中止请求，但不能保证已经处理的调用不计费。
- AI 优化和对话调整需用户确认才进入正文，保留历史版本；模型可能误改或补充细节，应用前必须核对。精简、扩写和配图未开放。
- 无产品账号、遥测分析或云端作品同步。受控公网测试使用共享的反向代理访问保护，它不是个人身份系统；通过后同事仍只看到自己当前浏览器与固定 Origin 的 IndexedDB。localhost、其他域名/协议/端口和其他设备的数据不会自动出现或上传。
- 公网网关只在固定 HTTPS Origin 后提供，应用端口保持回环。代理关闭访问日志；服务日志只含请求标识、动作、状态、耗时、token 数或错误类别，不记录正文、聊天、音频、Cookie、访问凭据、Key、签名 URL 或上游私密响应。
