# 数据和隐私

- 作品、会话和历史版本持久保存在当前浏览器 IndexedDB。清理数据、隐私模式或浏览器回收可能造成丢失，请定期导出备份。
- JSON 包含作品、会话和历史明文，TXT 包含文章及待确认编辑，请妥善保管，不上传代码仓库。
- 语音需用户同意与麦克风授权；音频通过本地服务发送腾讯云识别，腾讯云侧适用其服务设置和条款。
- 本产品不持久保存原音，不发送完整文章给识别服务，不记录正文或音频日志。
- 常规优化、润色文笔、文字追问和对话调整会在首次同意后，经本地服务向 DeepSeek 发送当前标题/正文、选取的历史版本及消息；DeepSeek 侧适用其服务设置与条款。不要发送不希望交给外部服务的私密内容。
- DeepSeek Key 只由服务端读取，不进入客户端；本产品不记录 Key、文章或会话日志，不自动重试计费请求。关闭/取消会尽力中止请求，但不能保证已经处理的调用不计费。
- AI 优化和对话调整需用户确认才进入正文，保留历史版本；模型可能误改或补充细节，应用前必须核对。精简、扩写和配图未开放。
- 无账号、遥测分析或云端作品同步；本版本网关不适合直接暴露公网。
