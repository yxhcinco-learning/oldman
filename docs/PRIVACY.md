# 数据和隐私

## 本地作品与微信身份

- 网页端作品、采访素材、会话和历史版本保存在当前浏览器 Origin 的 IndexedDB；小程序端保存在当前微信用户、当前 AppID 与当前设备隔离的本地用户文件。两端都不是云备份，清理数据、换设备、换微信、换 AppID 或浏览器回收可能导致原数据无法读取，请定期导出 JSON 备份。
- 小程序打开时用 `wx.login` 的临时 code 建立内部业务会话，只保存内部用户、当前 AppID 下的 OpenID、一次性 code 哈希和业务 token 哈希；不请求或保存手机号、头像、昵称，也不把身份作为作品所有权或恢复密钥。服务端身份库不保存正文、采访素材、会话或备份。
- 身份库保存在服务器项目专用的 `/var/lib/suiyue-yousheng/auth.sqlite`，与代码 release 分离并在迁移前做 root-only 备份。业务 token 只在服务端保存 SHA-256 哈希；一次性 code 只留哈希并按期限清理。代码回滚不得删除身份库，库不可用时在线功能关闭而不是创建假用户。
- JSON v4 以明文包含作品、会话、历史版本和每篇作品的 AI 来源披露；TXT/复制包含待对外使用的正文及必要的可见 AI 辅助说明。文件由用户自行保管，不上传代码仓库；导入只创建新副本，不迁移 token 或 OpenID。

## 话题编辑数据

- 独立 `topics.sqlite` 只保存编辑话题、不可变修订、AI 生成计数与固定状态、五席排期、单一管理员、后台会话散列和操作审计，不保存用户文章、采访回答、原音或用户端身份资料。话题库与 release 分离，并和身份库分别备份与恢复。
- 管理员密码只以服务端 scrypt 散列配置；登录 Cookie、CSRF 和会话 token 使用随机值，数据库只保存散列。审计只记录操作者、动作、实体、时间和非敏感差异摘要，不记录密码、Cookie、CSRF、DeepSeek Key 或上游原始响应。密码轮换、退出和过期会撤销会话。
- 编辑主动生成候选时，引子文字、链接、联网开关和生成时间会经服务端发送给 DeepSeek；链接存在时模型会使用服务端 web search。系统只保存候选结果和模型/token/搜索次数/错误类别，不保存思维链。引子不得包含用户私密文章或未经授权的个人资料。
- 发布话题允许 0–5 条来源。来源为空时用户端不显示来源区域；存在来源时公开显示编辑确认的标题、发布者、URL 和日期。话题数据库失败时公开热门与后台返回服务不可用，不用静态假数据掩盖故障。

## 语音转文字

- 只有用户在正文、小文输入框或采访回答处长按语音后，客户端才调用微信隐私授权和 `scope.record` 麦克风授权。拒绝、短按、授权期间松手或切后台都不会暗中开始录音，文字输入和本地写作仍可使用。
- 当次 PCM 音频通过岁月有声服务端网关发送腾讯云实时语音识别，只把识别文字放入当前输入位置；不会自动发送小文、应用正文或保存原音文件。腾讯云侧的数据处理适用其服务设置与条款。
- 网关不接收整篇文章用于语音识别，不记录正文或音频日志；连接有时长、字节、缓冲和并发限制，结束、取消或异常时释放录音与 Socket。

## 小文与 DeepSeek

- 只有用户明确点击发送、整理或重试后，网页或小程序才显示数据去向说明；同意后，经岁月有声服务端网关向 DeepSeek 发送当前标题/正文、选取的历史版本及消息。本轮需要时还会发送该作品保存的话题背景和所选采访回答。拒绝后请求不发送，本地写作、文字输入和语音转文字仍可继续。
- DeepSeek Key 只由服务端读取，不进入客户端；本产品不记录 Key、文章或会话日志，不自动重试计费请求。关闭/取消会尽力中止请求，但不能保证上游已经处理的调用不计费。不要发送不希望交给外部服务的私密内容。
- 小文的回答和完整候选持续显示“AI 辅助生成 · 请核对”。候选需用户明确应用才进入正文；用户原始回答、手写正文和话题来源不会被笼统标成 AI 输出。模型可能误改或补充细节，应用前必须核对。
- 一篇作品只要历史中存在已应用的完整 AI 候选，就保持保守的 AI 辅助披露；后续手改或恢复不会抹掉历史。未采用候选不会让正文导出被误标。对外复制和 TXT 会带可见说明，JSON v4 同时保存机器可读来源与用户可读说明。

## 网络、匿名运营事件与日志

- 无手机号注册、第三方分析或云端作品同步。H5 只为“打开应用、查看话题、开始空白/话题/采访写作、成功导入/导出备份”七类低频动作发送第一方匿名事件。请求体只有固定事件名，不含任意属性、用户/设备标识、话题/作品 ID、标题、正文、采访、搜索词、URL 或客户端时间；失败不排队、不保存、不重试，也不影响本地操作。
- 匿名事件入口保持在用户网页的 Basic Auth 后，同时接受 Nginx 按 IP 限流和应用全局限流。网关只把事件合并为当前进程内的计数；管理员“运行监控”只显示 15/60 分钟与进程累计的请求量、状态、固定错误、延迟和 token。聚合不含 requestId、IP、User-Agent、Header、原始请求或个人轨迹，服务重启即清空。
- 公网网关只在 Nginx 后提供，应用端口保持回环。代理与应用日志不得包含正文、聊天、音频、OpenID、session key、Cookie、Authorization、访问凭据、Key、签名 URL 或上游私密响应；单条安全日志只允许请求标识、固定动作、状态、耗时、token 或固定错误类别，进程内监控只保存不含请求标识的聚合。
- 用户网页继续由 Basic Auth 保护；公开已审核话题和明确列出的小程序登录、AI、语音票据/WSS 路径绕过该浏览器认证，随后仍由 IP 限流、业务 token 或单次 ticket 保护。内部 `/admin/topics` 和管理 API 也绕过 Basic Auth，改由独立后台登录、HttpOnly/SameSite/Secure Cookie、精确 Origin、CSRF、JSON 与限流保护；用户端 Basic Auth 凭据不能替代后台登录。小程序语音 URL 的 ticket 不写入访问日志，未列出的 API 直接拒绝。
- 正式小程序上线前还需在最终 AppID 下配置并复核微信用户隐私保护指引、麦克风用途、request/socket 合法域名、第三方处理说明和 AI 生成服务标识。开发者工具中的临时 AppID 预览不代表平台审核或法律合规结论。
