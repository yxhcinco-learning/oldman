# 小程序 AI 标识与隐私提审清单

本清单用于最终 AppID 的体验版和正式提审准备，不代表已完成微信审核、备案、算法/生成合成服务合规判断或法律审查。临时借用 AppID 只可验证界面和文件输出。

## 代码内可验证项

- [x] 小文返回的只读回答、采访追问和完整候选附近持续显示“AI 辅助生成 · 请核对”。
- [x] 候选预览说明确认前不进入正文；用户手写正文、原始采访回答和话题来源不显示模型来源标签。
- [x] 只有 `status=applied`、带完整候选和有效 `appliedVersionId` 的 turn 触发作品 AI 辅助披露；待应用、未采用、失败和纯用户作品不触发。
- [x] 应用后的手改、撤销或恢复不改写既有 turn，历史披露仍可追溯。
- [x] 对外复制和 TXT 在需要时加入可见说明；JSON v4 同时保存 `aiAssisted`、依据、已应用候选计数和用户可读说明，并在导入时与会话交叉校验。
- [x] 小程序只在用户发送/整理/重试时显示 DeepSeek 数据去向说明；拒绝不发送，仍可本地写作。
- [x] 麦克风只在长按达到阈值后调用微信隐私授权与 `scope.record`；拒绝、短按、后台和中断保留文字退路，原音不持久化。
- [x] 当前开发者工具不接受 `scope.record`/`getRecorderManager` 的 `app.json` 静态声明；`RecorderManager` 只会在用户主动长按并通过运行时隐私与 `wx.authorize` 麦克风授权后启动，仓库不含 AppSecret。

## 外部动作闸门

- 上传体验版、提交审核和发布为三个独立外部动作，分别等待用户明确授权。
- AppSecret 只由用户手工写入服务器 `/etc/suiyue-yousheng/runtime.env` 的 `WECHAT_MINIPROGRAM_APP_SECRET`，验收只报告“已配置/未配置”，不读取或回显值。
- 正式提审前复核[《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)及当时微信平台要求；当前实现和临时 AppID 预览不能替代最终合规判断。
