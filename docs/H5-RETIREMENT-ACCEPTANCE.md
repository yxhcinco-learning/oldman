# H5 退役与工程边界验收（2026-09-06）

## 用户确认与实际范围

小程序唯一用户端，网页仅运营后台。H5 不是仅停止维护，而是把独有源码/资源/预览/测试移动至 archive/h5；文档历史归档至 docs/archive/h5。服务与后台的旧 lib/features 协议导入改为 packages/core，后台根路由重定向 /admin/topics，独立全局样式不加载 H5/Tailwind。

移除 idb、fake-indexeddb、Tailwind 与其 PostCSS 插件直接依赖并更新锁文件；保留后台所需 React/Vinext。npm 脚本明确命名 admin/server，类型/Lint/测试排除归档，Git 发行归档排除 archive/ 和 docs/archive/。后端兼容 API 原样保留且不再依赖客户端实现；没有修改线上路由、秘密或数据库。

README、AGENTS 规范入口、产品、架构、开发、隐私、设计、OpenSpec 生成上下文和现行任务已对齐。旧 H5 专属任务是取消维护，不标作测试通过；小程序/核心/服务待办留在两个活跃变更。
