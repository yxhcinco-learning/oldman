# 小文文章伙伴验收

日期：2026-08-31  
变更：`promote-xiaowen-writing-companion`

## 范围与结论

本轮把编辑器中没有实际能力的“聊天”占位与独立优化菜单移除，直接提供叶片“小文”文章伙伴入口。该入口收敛不改变此前“聊天”概念的产品含义。正文输入使用单槽位目标模式按钮；小文默认以约半屏且不超过440px的紧凑面板打开，只提供自由文字、会话语音和发送，不展示预设快捷指令，同时保留候选确认、修改记录及可收起的后台请求状态。

代码、专项自动化、完整检查、生产构建、四尺寸真实浏览器和两次受控 DeepSeek 联调均已通过。物理 iOS Safari / Android Chrome 仍缺本次变更的独立证据，因此 OpenSpec 变更保持活动，不把桌面响应式结果写成真机结论。

## 自动化证据

- 服务端 prompt：`接着问我` 只基于正文接住真实细节并问一个问题；`讲清楚了吗` 最多指出三处或明确已清楚；两者不得返回候选正文。
- 控制器：内部精确提示继续复用 `question`，意外 `body` 被删除并保存为 `answered`；`regular / polish` action 继续兼容旧会话，但正式界面不再直接派发这些快捷 action；JSON v1/v2 无迁移。
- 编辑器：文字态显示目标麦克风、语音态显示目标键盘；切换不自动录音；聊天占位、优化菜单及未开放 toast 不再渲染。
- 小文：直接紧凑打开且输入不自动聚焦；显式展开/收起、输入聚焦展开、无预设快捷指令、52–148px输入、点按语音和发送均有回归。
- 生命周期：Escape/关闭恢复入口焦点并保留当前作品未发送输入；进行中请求收起后不中断，入口依次显示处理、新回复或失败；离开作品清空内存 prompt 并取消活动请求。
- 兼容：自由 `chat` 回答/改文、授权、候选预览/应用/放弃/撤销、引用、修改记录、恢复与存储失败回归继续覆盖。

## 浏览器与尺寸

在内嵌 Chromium 中复用 `localhost:3001` 的非敏感测试文章与长会话，并以独立 `localhost:3011` Origin 创建空会话。不清空原 Origin 数据，不打开麦克风。

| 视口 | 紧凑 / 展开面板 | 会话输入区 | 溢出结果 |
| --- | --- | --- | --- |
| 360×640 | 360×360 / 360×576 | 文字、语音、发送可见；预设快捷项 0 | `scrollWidth = clientWidth = 360` |
| 390×844 | 390×439 / 390×760 | 文字、语音、发送可见；预设快捷项 0 | `scrollWidth = clientWidth = 390` |
| 430×932 | 430×440 / 430×839 | 文字、语音、发送可见；预设快捷项 0 | `scrollWidth = clientWidth = 430` |
| 1280×900 | Echoes 画布与面板均为 800px 宽；面板 440 / 810px 高 | 文字、语音、发送可见；预设快捷项 0 | `scrollWidth = clientWidth = 1280` |

紧凑打开时焦点在“收起小文”而不在输入框；显式展开、输入聚焦展开、Escape/收起和入口焦点恢复均通过。未发送文字在收起/重开后完整保留；另一 Origin 的本地失败请求收起后，入口正确显示“需要处理”。本次追加回归确认四种尺寸均无预设快捷按钮或遗留快捷容器，输入、语音和发送可见；未点击发送，因此没有产生模型请求。

本机已保存的长会话在四尺寸可滚动，并实际打开失败记录、已采用/未采用候选全文和修改记录；待应用候选的“先不修改 / 应用优化”及保存失败由自动化覆盖，浏览器回归不为制造证据而改写原测试文章。正式 `localhost:3001` 控制台无 warning/error。

## 外部服务、隐私与费用

- UI 打开、展开、收起、提示展示和语音按钮本身不得调用 DeepSeek。
- 2026-08-31 实际调用 DeepSeek 恰好两次，均为非敏感测试文章的只读 `question`，不重试、不批量、不压测。“接着问我”用 3616 输入 / 33 输出 token、约 1.0 秒，接住“老槐树下休息”并只问了一个问题；“讲清楚了吗”用 3741 输入 / 58 输出 token、约 1.7 秒，明确判断时间、人物、地点、事件和感想已清楚。两次都不含候选正文，合计 7357 输入 / 91 输出 token。
- 本轮不部署、不推送、不读取凭据。真实请求只处理已标明的本机测试文章；未发送 composer 只存在当前作品内存，会话与候选仍按现有 IndexedDB/JSON v2 边界保存。
- 腾讯 ASR 与真实麦克风不在自动回归中启用；真机结果必须单列来源。
