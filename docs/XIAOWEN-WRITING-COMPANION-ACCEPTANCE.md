# 小文文章伙伴验收

日期：2026-08-31  
变更：`promote-xiaowen-writing-companion`

## 范围与结论

本轮把编辑器中没有实际能力的“聊天”占位与独立优化菜单移除，直接提供叶片“小文”文章伙伴入口。该入口收敛不改变此前“聊天”概念的产品含义。正文输入使用单槽位目标模式按钮；小文默认紧凑打开，提供四个快捷意图、自由文字/语音输入、候选确认、修改记录及可收起的后台请求状态。

当前代码与专项自动化已经通过；完整检查、构建、四尺寸真实浏览器和真实 DeepSeek/物理设备证据在下文按实际结果记录。缺少物理设备证据时变更保持活动，不把模拟结果写成真机结论。

## 自动化证据

- 服务端 prompt：`接着问我` 只基于正文接住真实细节并问一个问题；`讲清楚了吗` 最多指出三处或明确已清楚；两者不得返回候选正文。
- 控制器：两个快捷项复用 `question`，意外 `body` 被删除并保存为 `answered`；`帮我理顺 / 润色文笔` 分别保留 `regular / polish` 请求，显示文案不进入服务端 prompt；JSON v1/v2 无迁移。
- 编辑器：文字态显示目标麦克风、语音态显示目标键盘；切换不自动录音；聊天占位、优化菜单及未开放 toast 不再渲染。
- 小文：直接紧凑打开且输入不自动聚焦；显式展开/收起、输入聚焦展开、两列四个至少48px快捷项、52–148px输入、点按语音和发送均有回归。
- 生命周期：快捷项不读取或清空未发送文字；Escape/关闭恢复入口焦点并保留当前作品输入；进行中请求收起后不中断，入口依次显示处理、新回复或失败；离开作品清空内存 prompt 并取消活动请求。
- 兼容：自由 `chat` 回答/改文、授权、候选预览/应用/放弃/撤销、引用、修改记录、恢复与存储失败回归继续覆盖。

## 外部服务、隐私与费用

- UI 打开、展开、收起、提示展示和语音按钮本身不得调用 DeepSeek。
- 真实 DeepSeek 只允许两个非敏感短请求，各对应一个只读快捷意图；上限两次，不重试、不批量、不压测。未实际执行前不宣称模型效果。
- 本轮不部署、不推送、不读取用户文章或凭据。未发送 composer 只存在当前作品内存；会话与候选仍按现有 IndexedDB/JSON v2 边界保存。
- 腾讯 ASR 与真实麦克风不在自动回归中启用；真机结果必须单列来源。
