# AI 输入与优化提示 · 本地验收（2026-08-30）

## 范围

本次修正文章会话输入框点击后左右聚焦线被裁切的问题，在输入框内增加“按住说话”听写，并为首次写到一定长度的用户增加一次弱提示。提示按用户反馈缩短为“写好后，点‘优化’帮您整理文章。”，不抢焦点、不要求确认，约6秒自动消失。

会话语音复用正文录入已有的腾讯云 `SpeechSession` 和长按手势。识别文字只追加到可编辑的会话输入框，用户仍需点击“发送”；取消恢复录音前输入，关闭和失败停止录音并保留可用文字。正文达到80个非空白字时显示一次优化提示，显示时即在当前浏览器记为已展示。

## 浏览器回归

在内嵌浏览器复用“AI 功能验收（测试文章）”，先记录原文，临时补写文字触发提示，验收后恢复原文并等待本机保存。没有发送会话消息、应用候选、同意麦克风或产生外部请求。

- 390×844 下，弱提示为250×71px，显示指定短文案；正文输入保持焦点，页面宽与 viewport 同为390px；6.2秒后提示消失。
- 会话输入框聚焦后使用森林绿边框和1px内部描边，外部 outline 为0，四边均在弹层内。
- 360×640、390×844、430×932、1280×900 下，输入框宽分别为320、334、374、744px；页面 `scrollWidth` 分别等于360、390、430、1280，无横向溢出。
- 四种尺寸的“按住说话”均为114×48px，位于输入框右下且不遮住正文输入；发送按钮继续独立显示。
- 测试文章最终正文与验收前完全一致。

## 边界

- 本轮没有做真实语音识别或手机真机权限测试；自动化只验证状态路由和文字保留，不代替真实麦克风体验。
- 会话听写不是自动来回的语音聊天，不自动发送给 DeepSeek。
- 优化提示状态只在当前浏览器 `localStorage` 保存，清理浏览器数据后可能再次出现，不进入备份或跨设备同步。
- 未部署；原 `productize-local-writing` 的远端、真机和目录清理待办继续保持活跃。
