## 后续决策规则

- “网页”仅指运营后台，不能再泛指用户端；“跨设备”默认同账号的小程序设备，不包含 H5。
- “看看后端是否需上线”只检查后端差异，不自动发布网页；后台、小程序上传、线上停站分别说明范围并遵循授权。
- H5 独有 UI、IndexedDB、浏览器采音及四尺寸人工验收退出产品门槛；共享领域、协议、安全和备份规则继续有效。
- 历史“双端”条款按本次退役范围解释，活跃待办以更新后的清单为准；小程序缺陷、新 AppID、真实模型待验项不能顺带勾选。
- 云端作品、账号管理及同步只是下一阶段方向，尚未实现；微信最小身份和本地 revision 不是完整账号/同步系统。

## 依赖与线上边界

服务端 AI/语音/话题和后台类型直接从 packages/core/src 导入；旧 H5 lib 与 features 兼容入口已归档。后台使用独立样式，根路由不再加载 ProductApp；check/build/CI 只覆盖活跃工程，发行归档排除 archive/ 和 docs/archive/。

本次是本地清理，没有部署、停服务、清数据或撤销鉴权。线上版本按部署记录，不因本地根路由变化自动退役线上 H5。归档可由 Git 恢复，没有删除用户作品。
