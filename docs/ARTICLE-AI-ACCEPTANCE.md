# 文章 AI · 本地验收（2026-08-28）

范围：常规优化、润色文笔、文字追问；每篇文章共享持久会话和版本，完整预览后确认写回。模型为官方 `deepseek-v4-flash`。没有实现自由指令改写、语音聊天、精简/扩写/配图，没有发布。

## 浏览器验收

在 `http://localhost:3001/` 新建“AI 功能验收（测试文章）”，只使用编写的公园散步样文，没有读取用户私密作品或使用麦克风。测试文章和记录保留在该浏览器中，未自动删除。

- 常规优化：首次同意、完整结果、原文对照、放弃、应用、刷新后保留均已检查。
- 同篇追问：常规优化后手动移除老槐树句子，提问找到原文，两个真实引用按钮可打开；确认恢复后正文和历史仍保留，刷新可读。
- 润色结果与本轮正文相同时，前端和服务端均显示“本次保留原文，未产生正文修改”，不会沿用模型虚构的本轮修改说明。
- 使用不读取 Key、不发外部请求的临时本地网关验证点击取消、上游 500 的中文错误与显式重试、生成候选后手改导致应用禁用。测试结果明确标注“不来自模型”，未作为真实生成效果证据。测试网关已停止，正式网关恢复，`/api/ai/status` 返回 DeepSeek / configured:true。
- 原生 dialog 在内嵌浏览器中仅靠 cancel 事件未响应自动化 Escape；补充键盘处理后，Escape 可关闭并恢复“文章优化”入口焦点。测试同步覆盖。

## DeepSeek 真实联调

本轮真实调用上限由最初五次增至七次，调整前均说明原因；以下保守计入一次中断请求。最终没有超过七次，不做自动重试、循环测试、充值或计费调整。

| 次序 | 操作 | 实际结果 |
| --- | --- | --- |
| 1 | 非敏感 JSON 连通检查 | HTTP 200，35 输入 / 5 输出 tokens |
| 2 | 常规优化 | 返回全文并补逗号，但漏改“走的很慢”；未采用 |
| 3 | 常规优化中断 | 开发热更新取消，未应用；是否已计费未知，保守计一次 |
| 4 | 常规优化复测 | 补逗号并改为“走得很慢”；保留人物、老槐树、两个苹果和八元钱；应用后刷新可读 |
| 5 | 润色文笔 | 返回完整正文但与当前相同，说明重复上轮修改；未采用 |
| 6 | 润色文笔复测 | 历史与当前任务分开后仍偏保守，未产生正文差异；未采用，随后增加程序比对保护 |
| 7 | 文字追问 | 找到手动移除的老槐树原句，引用真实旧版本，并据 manual 来源说明手改后的差异；未自动改文 |

另一次开发服务重启期间的浏览器连接失败没有到达上游，不计为真实调用。后续本地替身请求也不计入这七次。

样文约百字，每次只带本篇少量历史；按当日[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)的输入缓存未命中 ¥3/百万 tokens、输出 ¥9/百万 tokens 粗估，本轮为不足一元的小规模测试，**不是实际账单核算**。除连通检查外，本轮未留存逐次 token 用量；中断计费也未核对，不报告虚构的总 tokens 或精确费用。

真实结果证明官方鉴权、全文返回、常规纠错、会话历史追问与引用链路可用；**短样本没有证明润色带来可感知的文笔提升**。模型可能偏保守或改错事实，完整预览、无变化提示和版本恢复仍是必要保护；后续应以用户实际文章评估效果，不用替身结果代替文笔质量。

## 边界与交付

- 当前最多 12000 字符全文；预算内选择历史并说明省略数，本机保存的旧版本不自动裁剪。记录前已丢失的内容无法恢复。
- JSON v2 保留会话和版本，v1 可导入；原 10MiB 导入限制仍在，历史会增大备份体积，当前不支持超限备份恢复。
- 首次发送需同意 DeepSeek 数据去向；Key 只在服务端，普通本机编辑不依赖 AI 服务。取消不能保证上游已处理部分免计费。
- 已完成范围按 `add-article-ai-session` 同步与归档；`productize-local-writing` 的远端/CI、真机和残余目录清理仍待完成。本地提交，不推送、不合并、不发布。
