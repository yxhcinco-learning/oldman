# 小文当前流程与债务

2026-09-06：仅小程序是用户端。旧双端审查原文已归档至 [历史流程记录](archive/h5/XIAOWEN-FLOW-REVIEW.md)，不是后续任务清单。H5 结果保存救援和浏览器样式问题退出维护；共享/小程序问题保留。

## 三个独立状态

- conversation.mode：访谈是否开启，收起不退出。
- turn 状态：请求等待、失败、取消或结果，不与模式混为一谈。
- 正文/版本与采用：生成不等于采用，撤销不删除会话历史。
