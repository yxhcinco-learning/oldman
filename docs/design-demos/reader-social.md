## 希望形成的闭环

好友分享一篇文章 → 访客读到完整内容 → 想点赞、评论、收藏、送花或关注 → 主动微信登录 → 完成刚才的互动 → 从收藏、关注列表和每日小花再次回来。

现行产品先登录才能阅读。本提案建议为作者明确同意公开的文章增加游客阅读例外，其他写作、个人数据及互动写入继续登录。旧文章默认保留原登录受众，由作者主动开放；新投稿清楚说明并确认访客可读，不能直接批量放开历史正文或头像。

H5 是小程序页面的独立设计样稿，不是重新启用 H5 用户产品。本轮未修改真实小程序、服务、数据库或现行正式规格。

## 页面与主要交互

| 页面 | 评审重点 |
| --- | --- |
| 分享阅读 | 正文先行；作者旁关注，页头分享，底栏评论、点赞、收藏、留言数、送花 |
| 评论 | 先起草，点击发布才登录；登录后原文字仍在，再次发布；明确待审仅自己可见 |
| 礼物面板 | 小花花选中、库存和今日领取状态；文房四宝灰色且禁用；每次送 1 朵 |
| 作者主页 | 默认头像、公开名字、文章、关注状态；不同作者有各自文章 |
| 我的 | 保留创作入口与文章摘要；增加关注/粉丝/互关、收藏和小花花 |
| 我的关系 | 关注、粉丝、互关分栏；回关形成互关，取消只改变自己发起的方向 |
| 收藏 | 仅本人可查，点开原文；失效文章只留占位并可移除 |
| 小花花 | 库存、每日到账与赠送记录，笔墨纸砚不可获取 |

登录弹层按当前动作解释用途：点赞、收藏、关注在登录后续接一次；评论回到输入框，送花回到面板，都需要再次明确确认。取消登录不改变互动，保留原文位置和本次评论草稿。

评论与草稿按文章区分，赠送记录按文章归属，再汇总到对应作者。自己的评论可删除，其他人的已公开评论可举报；原型里的审核中不会自动变成已公开。默认评论是已审核的虚构示例，运营审核本身留待实施，不用 H5 模拟结果证明真实审核。

## 提交本次评审的默认规则

- 小花花：账号每天首次有效登录或有效会话当天首次进入自动领取 **3 朵**，每次送 **1 朵**，可累计、不设过期；按服务端北京时间日期去重。接收者只增加获赠数，不增加可送余额；不做购买、兑换或提现。
- 礼物：**小花花、笔、墨、纸、砚**。文房四宝只有灰色展示，没有获取、支付或赠送入口。
- 评论：一级纯文字 **1–300 字**，**先审后显**；草稿只留本次运行，自己的审核中评论明确标记，不计公开数量。
- 关系：关注、粉丝和互关；名单与收藏仅本人可查，作者页呈现公开汇总。用户名用于显示，关系绑定稳定公开作者 ID。
- 公开范围：作者主动同意访客公开；历史文章维持原登录范围，个人自选头像继续私有。

这些参数随本次页面一起确认，可以在开始实施前调整。首期不增加私信、楼中楼、评论点赞、消息推送、购买和推荐算法。

## 如何体验

宽屏左侧切换 8 个页面，顶部可选 360×640、390×844、430×932，右侧显示页面思路。左侧“查看不同状态”提供访客、已登录、新用户空态、花用完、网络失败和文章撤下。切换状态会重建对应示例；切换页面保留本次操作。直接查看“我的”等私有页面的评审快捷入口会设为示例登录状态，正式产品入口仍通过登录流程。

窄屏顶部有“设计演示”与页面/状态选择，不属于拟议产品界面。`?embed=1` 隐藏外围评审工具，展示纯手机画面；`screen` 可取 `reader`、`comments`、`gift`、`author`、`profile`、`relations`、`favorites`、`wallet`，`state` 可取 `guest`、`member`、`empty`、`zero`、`error`、`unavailable`。

建议顺序：

1. 访客阅读 → 点赞 → 取消登录 → 再次点赞并模拟登录，观察只加一次赞。
2. 写评论 → 登录 → 检查原文字还在 → 发布 → 查看“审核中” → 删除自己的评论。
3. 重置 → 送花 → 登录领 3 朵 → 确认送 1 朵 → 再查看库存，送完后按钮禁用。
4. 进入我的关系 → 粉丝 → 给陈静回关 → 查看互关 → 取消关注，再检查粉丝方向仍在。
5. 收藏文章 → 我的收藏 → 阅读并返回；切换撤下状态后查看失效占位，正常文章仍可阅读。

网络失败状态先展示文章重试。要查看登录失败，从该状态再打开礼物面板，点击登录，第一次失败、再次重试成功。该失败开关只模拟本次本地过程，不代表后端调用。

所有数据只在内存，刷新/重置清除操作。H5 不请求真实微信、账号、审核、礼物或任何外部服务；分享按钮只展示卡片和入口说明，不发送消息。复用仓库内 SVG 素材，不加载远程字体、图片或依赖。可直接打开 HTML；完整交互建议用上方本机预览。
