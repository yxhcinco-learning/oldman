# 个人中心与文章设计评审

[打开可交互 H5 Demo](author-center.html)。当前为 2026-09-08 方案 04，仅用于小程序界面评审，不连接真实账号、数据库或投稿服务。

“我的”展示可编辑头像与用户名、写作入口、一篇最近草稿和两条文章摘要；完整作者列表承载搜索、筛选、逐篇管理与回收站。公共文章列表负责阅读。热门沿用现行页面，本轮不另做设计。

本轮发表路径为：**原编辑器 → 发表设置 → 阅读预览 → 提交审核**。编辑 Demo 对照[当前编辑器](../../apps/miniprogram/miniprogram/pages/editor/index.wxml)：标题在页头点击修改、正文占满中部、原工具栏保留语音切换与小文，下一步保持右侧 112×56；新稿默认语音。缺标题沿用标题抽屉，正文为空不能进入设置。语音识别、小文会话和键盘行为继续以正式小程序为准，本稿不连接录音或 AI。

发表设置只显示紧凑标题/字数、必选封面、署名及适用创作方式，不展开正文。选图进入独立裁切，支持拖动与缩放，分别确认阅读/分享 5:4 和列表 1:1；取消保留原封面，再次调整保留构图。阅读预览展示封面、标题、署名和正文，只保留返回及提交审核。预览后改稿或改名需重新预览，以当前确认快照提交，成功明确显示已提交审核。

头像保留修改入口，本地选择的图片只用于本次演示，取消选择不改变旧头像。封面可以选择本机图片或使用示例图，在浏览器内生成两种裁切效果；不上传文件，不将这些效果计作微信原生选图/裁切或服务端图片处理验收。个人头像仍属于资料能力，公开阅读沿用当前投稿的数据边界。

手动导出与旧备份导入留在“设置 → 数据工具”，用于独立文字文件及历史数据迁入；日常保存由账号同步承担。这两项、登录及微信好友分享只演示入口，不调用真实功能。所有文章、头像、封面和操作仅保存在本次页面内存，刷新或重置会清除演示修改。

建议通过本地 HTTP 服务打开，当前预览地址为 `http://127.0.0.1:3845/`。静态素材复用小程序 SVG，不加载外部字体、图片或网络服务。直接打开 HTML 可看页面；完整选图与 Canvas 裁切以 HTTP 方式验证。宽屏提供 360×640 / 390×844 / 430×932 实际内容尺寸和页面/状态选择，窄屏直接显示页面。`?embed=1&screen=publication` 直接打开发表设置；其他页面为 `profile`、`library`、`articles`、`editor`、`preview`、`reader`。
