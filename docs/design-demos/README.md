# 个人中心与文章设计评审

[打开可交互 H5 Demo](author-center.html)。2026-09-08 按用户要求制作，作为小程序界面评审载体，未接入产品路由或任何真实服务。

本稿将三个页面分别设计：个人中心展示身份、写作入口、一篇最近草稿和两条文章摘要；完整作者列表承载标题搜索、状态筛选和逐篇管理；公共列表承载阅读，使用方形封面、标题、两行摘要及署名日期。用户看稿后再决定小程序实现，当前设计提议不替代现行正式规格。

直接用浏览器打开 HTML 即可，静态素材相对引用现有小程序 SVG；无远程字体、图片或其他网络依赖。宽屏有页面选择、360×640 / 390×844 / 430×932 尺寸及状态控制；窄屏直接显示页面。也可以通过本地静态服务打开。查询参数 `?embed=1&screen=profile` 可直接展示个人中心；其他可选页面为 `library`、`articles`、`reader`、`preview`。

可以点通：个人中心摘要、全部文章、标题搜索/筛选、逐篇管理、删除确认/撤销/回收站恢复、编辑/发表预览、修改署名/示例封面、提交审核/撤回、设置与资料抽屉。封面裁切、小文、微信实际分享、备份导入导出和登录只保留清楚的演示边界，不模拟已经调用真实功能。内容、操作与状态都在内存中，刷新可重置；桌面控制区也有重置入口。

验证：Chrome 实际渲染 360/390/430 三档的 5 个主要页面和桌面评审页；交互回归 29 项通过，无页面异常或外部网络请求。小屏首屏可看清第一条摘要及其状态，完整内容可滚动；评审尺寸切换使用实际 iframe 内容尺寸。截图和执行报告保留在忽略目录 `.tmp/design-demo/`；不把这些结果记作小程序或真机验收。

仓库完整 `npm run check`（413 项测试、严格规格、文档与边界）和 `npm run build` 通过。本轮只保存 HTML、评审说明与状态记录，未修改小程序运行代码、产品正式规格或部署配置，也未上传或发布。
