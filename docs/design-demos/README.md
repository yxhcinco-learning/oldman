# 个人中心与文章设计评审

[打开可交互 H5 Demo](author-center.html)。当前为 2026-09-08 **方案 06：手机反馈调整稿**，先供页面评审，不连接真实账号、数据库或投稿服务。已上线测试的客户端仍为方案 05 及其同步修复；本稿没有上传或部署，执行状态见[当前状态](../STATUS.md)。

“我的”展示可编辑头像与用户名、写作入口、一篇最近草稿和两条文章摘要；“最近在写”“我的文章”采用 16px 无衬线分组标签，文章放在缩进的浅色区域，真实标题保留 22–23px 衬线，避免分组与作品成为视觉上的同级。完整作者列表承载搜索、筛选、逐篇管理与回收站。公共文章列表负责阅读。热门沿用现行页面，本轮不另做设计。

本轮发表路径为：**原编辑器 → 发表设置 → 提交审核**，阅读预览按需要打开，不是必经步骤。编辑 Demo 保留[当前编辑器](../../apps/miniprogram/miniprogram/pages/editor/index.wxml)结构：页头点击改标题、正文占满中部、语音切换与小文仍在底部。小文改为 52px 高浅绿入口，下一步收为右侧 88×48 文字及箭头；新稿默认语音。缺标题沿用标题抽屉，正文为空不能进入设置。导航均左对齐，返回热区 48px、与标题间距 4px，右侧避让微信胶囊；占位提示、正文输入和语音态文字统一无衬线 18/32px 与相同起点，导航/抽屉/提示不再复用文章衬线字体。语音识别、小文会话和原生键盘仍以正式小程序为准，本稿不连接录音或 AI。

发表设置只显示紧凑标题/字数、必选封面、署名及适用创作方式，不展开正文；底部主操作为“提交审核”，右上角提供轻量“预览”。选图进入独立裁切，上方仅调整一次共同构图，下方实时展示 5:4 阅读/分享图及其中间的 1:1 列表图，两张效果只读，不是比例选项。支持拖动、双指、滑块与加减缩放；一次“完成”同时保存两图并返回设置，取消保留旧封面，再次调整恢复共同构图。底部取消、还原、完成固定对齐，完成为 104×48，不再出现下一张。阅读预览只展示实际内容，适用 AI 说明放在文末；预览后改稿或改名可以直接提交最新内容，不要求再次预览，成功明确显示已提交审核。正式实现仍须在提交内部执行同步、快照准备、版本及署名校验。

头像保留修改入口，本地选择的图片只用于本次演示，取消选择不改变旧头像。封面可以选择本机图片或使用示例图，在浏览器内生成两种裁切效果；不上传文件，不将这些效果计作微信原生选图/裁切或服务端图片处理验收。个人头像仍属于资料能力，公开阅读沿用当前投稿的数据边界。

手动导出与旧备份导入留在“设置 → 数据工具”，用于独立文字文件及历史数据迁入；日常保存由账号同步承担。这两项、登录及微信好友分享只演示入口，不调用真实功能。所有文章、头像、封面和操作仅保存在本次页面内存，刷新或重置会清除演示修改。

建议通过本地 HTTP 服务打开，当前预览地址为 `http://127.0.0.1:3845/`。静态素材复用小程序 SVG，不加载外部字体、图片或网络服务。直接打开 HTML 可看页面；完整选图与 Canvas 裁切以 HTTP 方式验证。宽屏提供 360×640 / 390×844 / 430×932 实际内容尺寸和页面/状态选择，新增“仅一篇审核中”状态，方便核对手机图中的个人中心。窄屏直接显示页面。`?embed=1&screen=publication` 直接打开发表设置；其他页面为 `profile`、`library`、`articles`、`editor`、`crop`、`preview`、`reader`。侧栏可直接进入调整封面，完成后仍回到同篇设置。
