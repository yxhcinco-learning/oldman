# 小文文章伙伴验收

日期：2026-08-31
变更：`promote-xiaowen-writing-companion`

## 当前结论

编辑器只保留一个“小文”入口。普通会话直接显示自由输入、点按语音和单一“发送”；从热门话题进入时，同一面板切换为聊天式采访。页头只保留修改记录与“收起小文”，已删除用途含混的尺寸切换按钮。

面板使用约 `min(72dvh, 620px)` 的稳定高度并受 Visual Viewport 约束。消息区独立滚动、输入区固定；关闭或 Escape 只收起面板，保留当前作品的未发送输入、会话、候选与进行中请求。

## 验证证据

- 自动化继续覆盖自由问答/改文、授权、候选预览/应用/放弃/撤销、修改记录、失败补救、收起恢复和话题采访。专项三个文件44项通过；`npm run check` 的24个测试文件、231项测试及全部静态检查通过，`npm run build` 的五阶段生产构建通过。
- 实页检查中，采访区只有“换个问题”、语音与“发送”三个可见按钮；没有“保存回答 / 继续问我 / 先暂停 / 回到文章”及素材勾选表单。
- “换个问题”取消额外水平内边距；四种视口中按钮文字与问题正文的左坐标差均为0，按钮高度保持44px并保留焦点样式。
- 四种视口结果：

| 视口 | 面板高度 | 输入区底部 | 文档宽度 |
| --- | ---: | ---: | --- |
| 360×640 | 约461px | 628px（距底12px） | 360 = 360 |
| 390×844 | 约608px | 832px（距底12px） | 390 = 390 |
| 430×932 | 620px | 920px（距底12px） | 430 = 430 |
| 1280×900 | 620px，宽800px | 888px（距底12px） | 1280 = 1280 |

四种尺寸的发送按钮均高48px、尺寸切换按钮为0，浏览器控制台无 warning/error。

## 外部服务与验收范围决定

本轮实页回归只读取话题列表和详情，没有调用 `/api/ai`，也未点击语音；新增 DeepSeek、腾讯 ASR 和麦克风调用均为0。此前该变更记录的两次受控只读 DeepSeek 联调属于历史证据，不是本轮调用。

2026-09-04，产品负责人确认当前小文功能及 Android 实际使用均通过，不要求代理重复整轮人工功能测试。当前没有可用 iOS 设备，iOS Safari 未验证并明确不作为本次归档门槛；不得表述为已通过 iOS 验收。基于既有自动化、四尺寸浏览器证据、历史受控 DeepSeek 证据和产品负责人验收，本变更归档；未来 iOS 兼容性检查属于可选增量。
