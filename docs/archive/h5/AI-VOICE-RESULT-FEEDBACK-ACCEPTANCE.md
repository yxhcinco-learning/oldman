# 小文语音与结果反馈 · 本地验收（2026-08-30）

## 范围与结论

用户在受控公网体验中发现两类问题：小文输入框的“按住说话”短暂显示准备麦克风后视觉回弹并未完成听写；应用候选后常驻成功条、单独一行修改记录和同等重量的查看/撤销按钮压缩了手机会话内容。用户同时确认同设备正文语音输入正常，因此本轮没有改写腾讯云协议、`SpeechSession`、正文语音舞台或授权数据，只收紧共享手势的结束判定和小文紧凑按钮展示。

现行行为：

- 小文按钮从指针按下开始保持赭色按压态；准备/连接显示“请继续按住”，录音显示“松开结束”，松开收尾显示“正在确认”。
- 指针普通 blur 不再结束长按，真实 `pointerup/pointercancel` 只停止或取消一次；键盘仍可用 Enter/空格长按并在 keyup、持有期间 blur 或 Escape 时结束。
- 正文语音原有授权、固定舞台、阶段节点、失败文字、待确认转写、完成与清空行为保持。
- 应用、放弃、成功恢复和复制成功使用约3秒非模态 toast；候选“已应用/未采用”等真实状态和修改记录继续持久。复制失败、正文冲突、覆盖风险与存储/网络错误仍持续显示。
- 会话“修改记录”移到页头48px图标操作；消息内“查看优化/调整结果”为主要操作，已应用候选的短“撤销”为同组次级操作，完整无障碍名称仍为“撤销这次优化/调整”。

## 边界

- 本轮没有部署到受控公网，线上仍需发布后复测；没有验证修复后的真实手机长按、Safari/安卓 Chrome 指针事件或真实识别准确率。
- 用户报告同设备正文语音输入正常是问题范围证据，不冒充本轮独立真机验收；本轮浏览器没有开启麦克风。
- 普通回归不调用计费服务，不评估新的模型输出质量；文章、候选状态、IndexedDB和JSON备份格式均未改变。
