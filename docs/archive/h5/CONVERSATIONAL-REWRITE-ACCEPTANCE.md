# 对话式改文 · 本地验收（2026-08-30）

本文保留双按钮阶段的设计与反例证据。后续入口已合并为一个“发送”，当前行为见 [统一发送验收](../../AI-UNIFIED-SEND-ACCEPTANCE.md)。

## 范围与设计

用户确认让小文在同一文章会话中按自然语言调整内容。实现新增 `rewrite` action 和“对话调整”版本来源，不改变 IndexedDB v2 或 JSON v2。小文输入区同时提供“问小文”和“调整文章”：不使用模型自动意图分类；问答继续只读，改文必须返回完整候选，经原文对照、确认、基准检查和事务保存后才写入，可放弃、撤销和恢复。

对话调整可执行明确的改写、删除、重排，也可使用用户本轮明确提供的新事实，不自动改标题。用户随后明确校正：文风改写必然改变表达，应允许合理修辞、情绪色彩和不改变核心事实的氛围描写；不能只因出现新词就判定错误。保护边界放在人物关系、谁做了什么、时间地点、数字、直接对话和事件结果等可核实内容，氛围性增写须在修改说明中披露。以上是模型约束，不是自动事实核验保证。

## 一次真实 DeepSeek 验证

只做一次短文调用，没有自动重试或额外付费验证。原文明确包含母亲、院子、兰花、去年春天和喝茶；要求“只把第一段写得更温暖自然，保留这些事实，不要改第二段”。

链路成功返回完整候选，保留了第二段及上述核心信息，并增加夕阳余晖、微风等氛围表达；同时把“去年春天种下”改成“我们一起种下”，新增母亲指向墙角、温柔说话等具体动作。按用户后续校正，前一类应结合文风请求合理看待，后一类改变了可核实的动作和共同经历，属于越界。修改说明没有披露这些具体增写。该候选在页面选择“先不修改”，状态保存为未采用；随后关闭弹层核对正文仍是原文。

据此增加两层保护：提示词区分文学表达与核心事实，明确“去年春天种下”不得改成“我们一起种下”、不得擅增人物动作，并要求加入氛围时在 answer 中披露；候选页提示文风会改变表达并可能加入氛围，重点核对人物、动作和经历。按预定上限没有再做第二次真实调用，因此只证明调用、候选、放弃和安全不写回链路，**不声称校正后的模型边界效果已经真实验证**。
