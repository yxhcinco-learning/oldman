# 常规优化口语书面化验收

## 范围

用户反馈常规优化后的正文与原文差异不明显：标点和分段有所整理，但“嗯、啊、吧、呢、嘛”、重复“然后”及松散口头句式基本未改。本次只调整 DeepSeek 常规优化的服务端任务指令及契约测试，不改变模型、接口、温度、润色文笔、对话改文、标题、会话、存储、确认写回、界面或部署。

常规优化现在要求把不承担事实、强调或情感作用的口语填充、重复连接和松散句式改为自然书面表达。允许为此替换必要措辞、合并重复表达和调整句式；不得补写经历、因果或背景，也不得机械删除有意义的方言、直接引语、情感和叙述者个性。

## 回归口径

用户提供的非敏感短样例保留以下核心信息：16 岁、从上海坐车到黑龙江、车程三天三夜、车上都是知青、有人哭闹、叙述者当时年纪小且不觉得苦而觉得新奇、窗外土地变宽、树木减少、土地变黑。效果检查须满足：

- “嗯、啊、吧、呢”等无意义填充显著减少，连续“然后”不再机械重复；
- “住 3 天 3 夜”等口头松散句在原意清楚时整理成自然完整句；
- 上述事实、否定、程度和情感保持，不增加政策名称、年份、具体地点或新的经历；
- 结果是平实书面叙述，不堆砌景物或情绪修辞；
- 修改说明只陈述本轮实际变化，候选仍需用户预览确认后才能写回。

## 真实效果检查

使用用户提供的上述短小非敏感样例，通过现有常规优化链路检查 DeepSeek；不批量、不做其他付费调用。

1. 第一次使用 989 input / 147 output tokens。填充词和重复“然后”明显减少，但把“我”扩大为“我们”、把不完整的“政策嘛”补成“政策下来”，且保留了不自然的“火车上住了3天3夜”。提示词据此增加主语、人称、残句和明确上下文口误约束。
2. 最终复核使用 1095 input / 177 output tokens。候选为：“我16岁那年，政策下来，我们从上海坐车到黑龙江。坐了3天3夜的火车，车上全都是知青，很吵，有的甚至在哭，有人在闹。那时候我小，不觉得苦，只觉得很新奇。看窗外，地越来越宽，树越来越少，一眼望不到头。土地也变成了黑色。”

结论：用户要求的口语书面化方向已明显生效——无意义填充和重复连接基本清理，松散句式及“住3天3夜”得到整理；但 DeepSeek 仍未遵守“我不得改成我们”和残句不得补成确定事件的明确约束。该候选没有写回任何用户文章。当前系统仍依靠全文预览、事实核对提示和用户确认阻止越界结果直接进入正文，不能宣称模型自动保证事实。两次合计 2084 input / 324 output tokens，达到调用上限后未再重试；本结果只证明本次书面化规则方向，不代表所有文章上的稳定质量。
