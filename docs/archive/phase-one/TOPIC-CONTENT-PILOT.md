# 议题写作首轮试点

状态：2026-09-04 产品负责人决定取消本变更的目标用户试点，不再作为 `add-topic-guided-writing` 的验收或归档门槛。本文仅保留当时的研究方案，不表示试点已执行，也不产生参与者证据。

## 目标人群与栏目

首轮聚焦 55—75 岁、有事业单位或相近专业工作经历、仍有文字表达意愿且日常使用微信的退休知识人群，优先邀请退休教师及教育工作者。内容先保持五个栏目：教育与职业、科技与生活、文化与阅读、退休后的学习、城市与家庭记忆。

正式种子目录位于 `server/topic-catalog.ts`，包含至少 20 张经来源核对的话题卡，覆盖当下事件、周期主题和慢议题。用户可见的主要入口为“直接写”“接受小文采访”；采访先用简短静态开场说明小文和一次一问的方式，再以消息、固定输入区和单一“发送”形成自然对话。“换个问题”只附着后续当前问题，“整理成文章”只在已有回答后出现；关闭时按真实内容进入文章或返回热门，不常驻暂停或返回按钮，也不出现第二个“聊天”助手。

## 两周人工试点

计划邀请 15—30 位目标用户，在两周内每天提供不超过三张话题卡，轮换比较三种呈现：仅事实摘要、摘要加中性相关切面、摘要加小文采访入口。参与者自行决定是否写、是否接受小文采访、是否分享，不要求打卡，不把阅读时长当作成功。

记录以下证据，且不采集正文内容：

- 话题曝光、打开、“直接写 / 接受小文采访”选择及首次有效输入；
- 是否形成可保存草稿、是否主动整理成文章、是否导出或复制；
- 采访中换题、收起和重开继续的次数；
- 对来源可信度、问题是否冒犯、文案是否显得说教的访谈反馈；
- 第二周是否仍主动返回写作。

本文件只是历史试点方案。任务 1.2 依据 2026-09-04 的产品范围决定关闭，而不是以组件测试、内部演示或 AI 反馈冒充目标用户证据；任何后续引用都不得声称本试点已经执行。

## 判断原则

若用户主要阅读而很少开始表达，说明产品退化为资讯入口，应减少摘要、加强个人角度或重新选择栏目。若采访明显增加用户原创材料但退出困难，应优先改善暂停和切换，而不是增加自动追问。若正常写作持续被选择，两条路径继续并存，不以采访取代编辑器。
