# Echoes of Time · 独立设计预览

基于找回的原版界面，按用户提供的 [DESIGN.md](DESIGN.md) 重做全部页面。用户已确认视觉方向，正式落地由 `adopt-echoes-product-design` 管理，唯一现行设计规范为 [DESIGN-SYSTEM.md](../../../../DESIGN-SYSTEM.md)。本目录仍是独立mock对照，不替代正式应用或使用正式数据。

## 运行

在仓库根目录执行（复用已安装的依赖）：

```sh
node previews/echoes-of-time/serve.mjs
```

浏览器打开 `http://localhost:3004/`。服务只监听本机回环地址，端口占用会报错，不自动改端口。修改预览源码后需要重启该命令并刷新页面。

仅重新生成单文件 HTML：

```sh
node previews/echoes-of-time/serve.mjs --build
```

生成文件：`outputs/echoes-design/echoes-design.html`。优先使用本地 HTTP 预览；文件直开是否可用取决于外部工具的执行策略。截图另存于同目录下的 `screenshots/`。

## 可以体验

- 三篇示例作品、继续编辑、新建、标题与正文输入、点击单段修改、当前页面内保存。
- 按住麦克风约180毫秒后模拟转写，松开查看结果，可继续说、清空、修改或完成；支持空格/回车操作。
- 文字模式展示桌面模拟键盘，也支持实体键盘。触屏设备使用原生输入框与系统键盘。
- 聊天引导、模拟回复、完成后整理正文。
- 类型、文风、分段/标点/小标题、配图、自定义要求、结果预览、应用与一次撤销。

**所有数据只存在内存，刷新恢复初始示例。** 语音、聊天和优化均为原型模拟，不读取麦克风，不调用真实服务或正式作品存储。

## 视觉口径

- 采用附件顶部色板，暖白 `#fbf9f8`、森林绿 `#153b2e`、赭色 `#944924`。正文中的羊皮纸色只用于插画。
- 标题使用 Noto Serif 类衬线字族，正文18px无衬线；Noto Serif / Manrope 未打包或联网加载，使用中文系统字体回退，不同设备字形可能略有差异。
- 移动端单栏，桌面最大800px；原有操作改为统一工具栏，转写区保留三行高度，麦克风在空闲/录入/确认状态间使用同一网格位置。
- Open Design 原型流程指导预览组织；本机未安装完整运行程序，使用现有 React/Vite 工具链实现。未修改正式产品样式和配置。
